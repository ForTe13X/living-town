# T2 前瞻注入实验 · 判卷规则（**预注册**）

写于 2026-08-01，**在任何一份回执产生之前**。基线 `d13f448`。
写下它的理由很直接：**我既是注入方又是判卷方**（docs/75 §二 验收 4 点名的那条局限）。
唯一能压住这条的东西，是**把判据在看见数据之前定死并落盘**。

## 一、判卷的三档（每条注入只能落一档）

| 档 | 判据 | 计入 |
|---|---|---|
| **HIT** | 回执**点名**了这条注入的那个具体东西（假值本身，或"位置 + 真值"），并**把它讲成 brief 错了** | 分子 |
| **PARTIAL** | 回执在相应位置写出了**真值**或**正确说法**，但**没有**把它呈现为对 brief 的更正（只是顺带写对了） | 只进上界 |
| **MISS** | 其余一切，含"我没核这一条"、含把 brief 的假话原样转述 | 分母 |

- 主口径 = **HIT / n**；上界口径 = **(HIT+PARTIAL) / n**。**两个都报，都带 Wilson 95%。**
- **不合并层。** 合并值只在显式要求时打印，且必须附"它没有意义"。

## 二、逐层的 HIT 具体长什么样

- **L1 行号**：说出"那一行不是 `_recompute_factions()`／真身在 `:3885`"之类。
- **L2 路径**：说出该文件不存在／真名是什么。
- **L3 符号**：说出该符号全仓查无／真名是什么。
- **L4 数字**：说出该数字与今天实测不符（**给出它自己测到的数或指出出处**）。
  ⚠ 仅"这个数看起来可疑/建议复核"= MISS，不是 HIT。
- **L5 假门断言**：说出那道门**不会**因此变红／它守的不是这件事。
- **L6 不可满足验收**：说出该验收条目**做不到**（或该判据结构上不可能成立）。

## 三、同时要记的两件事（没有它们，检出率是个没有零假设的数）

1. **假警报 FA**：回执把一句**本来是真的**话判成了错。逐条记。
   **D0 空白对照臂（未注入）上的一切"发现"都是这一栏的原料**——
   其中确为真错的记作 **野生发现 W**（它不是 FA，是这套方法论本来就在抓的东西）。
2. **证据类**（每条 HIT 都要记，这是 S2「证伪成本差两个数量级」那条论断的直接检验）：
   `ls/grep`（查文件或符号）· `read`（读代码/数据文件本身）· `xref`（读另一份 docs 交叉引用）·
   `rerun`（真的跑了 bench/门）· `reason`（没有证据，靠推理）· `unknown`。
   ⚠ **`xref` 要单列**：靠另一份文档抓到的，不证明棒子有能力核验，只证明仓库里有第二份副本。

## 五、预先声明"这个实验测不到什么"（不等跑完再补）

1. **棒子是只读的。** 真棒子的错误发现有一部分发生在**动手改的过程中**，本实验结构上够不到那一半。
2. **注入是被宣布过的**（A/B/D 臂的 prompt 明写要交 §4）。C1 臂是为量这一条差多少而设的，**只有一格**。
3. **判卷者=注入者。** 预注册压得住"看见数据再改判据"，**压不住**"我造的注入正好是我会去查的那种"。
4. **注入分布不是真实错误分布。** 六层是 docs/50 §四 当初拍的，不是从错误样本里学的。
5. **n 很小。** 逐层 n=4..6。区间会很宽，**宽就是结论的一部分**。
