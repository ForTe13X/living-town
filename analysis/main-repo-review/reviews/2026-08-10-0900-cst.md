```gdscript
return x       # 完全不衰减
return 0.0     # 一次瞬间清空任意 standing
```

而且自检直接调用 helper；未来若 nightly call-site 被改回旧公式或不再每三天调用，helper 仍会绿。故 commit 所称“旧实现必红”只对把旧公式放进 helper 的特定 mutation 成立，不覆盖真实集成路径。

补法不是再加宽泛性质，而是两层 oracle：

1. 精确表：`{-2,-1,-0.6,-0.2,0,0.5,1,2} -> {-1,0,0,0,0,0,0,1}`，并验证多步在 `ceil(abs(x))` 次内到零。
