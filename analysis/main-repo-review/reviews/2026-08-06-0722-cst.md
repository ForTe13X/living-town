## 本轮真实增量

`ce75142` 相对 `e2a85bb` 只增加三项：

- [设备触摸与音频报告](../../../docs/111-device-touch-and-audio.md)
- 两张设备截图
- 零代码、零测试、零 CI 配置改动

报告提供了有限但有价值的观察：

1. 旧 APK 中存在状态为 `started` 的 Android audio player；当前源码确实以数学方式生成非零 PCM，仓库没有 tracked 采样音频文件。
2. 点居民和详情面板在设备上可用。
3. 设备上的近期记忆出现“被婉拒”，为 live story outcome 语义冲突增加了一张可视样本；没有 event id，尚不能单靠截图证明两路文字对应同一事件。

其余主张存在明显过度外推：

- `state:started` 不能证明用户实际听到了非零音频，更不能证明音质、路由或媒体音量正确；没有录音或听感回执。
- “未请求 audio focus”不能直接推出与其他播放器、来电、前后台切换时双方都不会让路，这需要并发实验。
- Android preset 与模板存在不等于 export/install 路径已经跑通。
- `lastUpdateTime` 不是 build provenance；没有 APK SHA256、versionCode、嵌入式 git SHA 或 raw adb artifact。
- “第一次点空因为居民走开”没有视频、输入坐标和 agent position trace，只能标成推断。

触摸结论还有代码级反证。[第 59–72 行](../../../docs/111-device-touch-and-audio.md)标题写“九分之七”，正文写 `9/11`，而按 `·` 分组实际是 12 组。更重要的是，它把未测试项直接判成 keyboard-only；当前源码明确提供触摸等价入口：

- O 设置：[左上“设”按钮](../../../game/scripts/Main.gd)
- Space 暂停：设置面板速度栏的“暂停”按钮
- V 详情：右上“详情”按钮
- J 纪事：可点击的纪事摘要
- F5/F8：设置面板的存档/读档按钮

因此 docs/111 能证明“旧包上详情和点居民实测可用”，不能证明“只有两项可触摸”。下一次应按“能力 / 键盘快捷键 / 触摸等价入口 / exact-build 实测”四列重新测试，而不是把底栏文字是否可点当作功能是否存在。

该 APK 的更新时间是 2026-07-30，早于 Wave I 之后的改动，不能验收当前 HEAD。文档还公开了临时 pairing code、局域网 IP、设备型号和端口；即使大多已失效，也应按最小披露原则脱敏。
