### 背景（我已复核，给你坐标——但坐标本 session 常腐烂，你实读为准）

现状（U1/S1/W2/AA1 实测）：产出侧已是**宏观池**（`Sim._pool_rescale`：按 population/base 缩放 amount/inputs/cap/spoil/start_stock，N=12 逐字节不变），
**但产出【触发】仍绑少数具名工人**：`_produce_for` 只在某岗位持有人**在班且真的做了那个动作**时才产出。
克隆居民只拿 `{id, persona, spawn, home}`、**从不进岗位表** ⇒ N 涨而"面点师/渔夫"仍各只有一个。
⇒ **一个 baker 是否及时到岗决定整个产业的产出节奏**——这是"半宏观"：批量宏观了、**到达过程没宏观**。
AA1 实测：曾到达非小镇平面的 agent 数在 N=12/24/60 恒为 9（人口 ×5 而这个数不动）；
N=60 口粮左尾是"面点师+渔夫两个生产者一起低抽样"的联合分布尾（W2/T1）。
