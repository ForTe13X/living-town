> 一个**两位小数**在一份长文档里本来就会撞上，**邻近又恰好有"实测/更正"这类词**。

**两个分句都不成立**，我把命中位置打出来了：

- 假值是 `1.3`（**一位**小数），它命中的是 **`### 1.3 逐岗位在班完成次数` 这个小节编号**，不是任何测量值；

于是读它的人（S2 自己）只能看到"更正语"那一半。**判据的输出把自己的机制藏住了。**

## 三、前瞻实验的设计——**以及 v1 那次把它整个作废的泄漏**

### 3.1 v1：四根棒，三根的第一句话是 `git status`

v1 的隔离方式是 `git clone` 之后**把变异 brief `cp` 到工作区上**。
于是 `git status` 显示 ` M docs/71-…`，而 `git diff` **一次性交出全部注入**。

A1 逐字：

> `git status` 显示 `docs/71-wave-s-plan.md` 是 ` M`（工作区已改，未提交）。`git diff` 给出 **10 处改动**，
> 且它们**整齐地落在 5 个层各 2 条**……⇒ 这份 brief 极可能是 `brief_mutate.py inject` 的产物。

A2 逐字：

> `git diff` 显示相对 HEAD 有 **8 处改动**，下面 B/C/D/E 组里的问题**全部**落在这 8 处里。

C1 逐字（**而 C1 是提法对照臂，它根本没被要求找错**）：

> 工作副本里 `docs/64-wave-q-plan.md` 相对 `HEAD` 有未提交改动，**10 条注入的错误全在这个 diff 里**。

⇒ **它们不是"发现"了注入，是被递了答案。v1 四臂全部作废，一个数都不进分层表。**
v1 测到的是"棒子会不会跑 `git status`"（答案：会，而且与任务无关——连出方案的那根也跑）。

**这件事值得停下来看一眼，因为它正是本棒在指控别人的那个形状**：
一个**看起来完全合理的实验装置**，在**没有人去问"被试能不能从别的通道拿到答案"**的情况下，
产出了一批**读起来很像检出率**的数字。**如果我没有读那两份回执的 §〇，这一波会交出一个虚高的数**——
而它会被下一波引用。[docs/50 §八](50-wave-h-plan.md) 那个 30/30 的分母**是不是也这样**，
我无从判断（它的原始数据不存在），但**我现在知道这条路有多好走**。

⚠️ 另外 A1 抓到 v1 派棒 prompt 的第二个设计错误：它写"三根棒动手之前"，

### 4.2 ★ 提法对照：A2 ↔ C1（**同一份 brief，逐字节相同，只换派棒 prompt 的重心**）

>
> 公告效应**不改变棒子知道什么，只改变它写下什么**。而它为什么只打中 L3、打不中 L5/L6，机制是可以说清楚的：
> **一句假的"这道门管着你 / 不必自造对照"会改变方案本身，绕不过去**——
> 出方案的棒**不得不**处理它，于是它必然被写出来。
> 而一个**写错的符号名**，棒子心里改对就过去了：它不影响方案的任何一步。
> **⇒ 会被静默修好的错误，正是那些"不改变下一步该怎么做"的错误。**
>
> ⚠️ **n=2/层，一根棒对一根棒。这是一个信号，不是效应量。**
> 不要把它引用成"公告效应 = 一层"。
