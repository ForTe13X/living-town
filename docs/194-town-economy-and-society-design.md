## 二、设计

### 1 · 家计：挣钱才能过得好（想法 ①）

**家当（pantry）**：每户（按 home）一个小库存，只装"生活用品"类货：`口粮`（基本）、`杂货`（新货：肥皂/蜡烛/油盐，洗澡和做饭的舒适加成）、`糕点`（treat）。
- 在家吃饭/洗澡**先扣家当**；家当空 ⇒ 这件事照做（生存不变），但**质量降级**：need 补给打折上限（例：只补到 70 而不是 100）+ 一条"家里没东西了"记忆。
- **购物**：新动作 `采买`，在杂货铺/集市摊位（worksite 已有）付钱把货从镇库搬进家当。走 `_stock_move` + `transfer`，两条唯一通道都不用改。
- **没钱的兜底 = 大他者配给**：`coin < 配给线` 时可到教堂/镇公所领 `救济口粮`（口粮直接进家当，不收钱，记一笔"领救济"事件）。**被邻居看见 ⇒ 走现有 wealth gossip 管线**（面子成本），**不进 `_acceptance_margin`**（175 核心规则）。

**账单（bills）**：夜结时每户付固定开销，全部经 `transfer` 流向 **town_coin**（再按 §3 分给大他者）：
- `水电`（按户，固定）、`炭火`（冬季加倍，接 weather/季节）、`房租`（已有，保留）。
- **付不起 ⇒ 记欠账 `arrears`**（新字段，只增不减到付清为止），欠账不阻断任何动作；后果：①暖气/热水降级（洗澡补给打折）②欠账被知情者议论 ③欠满 N 天房东/镇公所上门（一个现成的 `confront` 冲突弧来源）。
- 这样"必须出去工作"的动机从今天的 `poor_line` 单一阈值，变成**持续的现金流压力**：月入 < 月出 的人会自然更常上工。

**作息表（schedule）**：给每个具名居民一张按相位的日程（`schedules.json`，按职业类型给模板、居民可覆写）：
`dawn 起床/早饭 → day 上班 → dusk 下班/采买/社交 → late 回家 → night 睡`。
- 日程只作**软偏好乘子**，接到现有 rhythm 抑制机制上（同一套 ≤1.0 设计：只推迟非当令的事，不加新吸引力），紧急需求照样打断。
- 周末/休息日：每 7 天一个休息日，班次关闭 ⇒ 社交/娱乐场所的自然高峰（§5 的活动安排在这天）。

**职业伦理（work record）**：每个岗位持有人一份 `出勤记录`：到岗晚、缺班、早退计数（相对日程表的班次窗口）。
- 后果只落**工资**（迟到扣 1、缺班不发）与**雇主/同事的看法**（一个独立的 `work_rep` 字段，只读进语音/Story/HUD），**不进生存产者决策**。
- 连续良好出勤 ⇒ 小额奖金（由镇库付）。这给"守秩序"一个正向回路，而不是只罚。

### 2 · 镇营设施：教堂、集市、酒店（想法 ②）

五座 docs/193 已开的设施 + §5 的新场所，统一成**镇营（town-owned）/外营（affiliate-run）设施**：
- **经营者 = affiliate**（外来员工，§4 的轻量人群里的"外来工"），**不抽居民劳动池**（175 §三的核心原则；这也正是 193 里 fun 访问会抢岗位的解法）。
- **收费**：进场/消费付小额费用（教堂免费，捐献自愿；集市摊位按件；酒店按晚；餐馆按餐）→ 进 **town_coin**。
- **税**：设施营收的固定份额按夜结上缴大他者（§3）。
- **开放时间**：设施有营业相位（接作息表）；关门时不出现在候选里。
- 解锁 fun 访问的前提：设施自己有人经营、有营业时段、收费 ⇒ 居民去之前要权衡钱 ⇒ 不会像 193 那样无代价地挤掉上班。**这一条要在 P2 实测**（N=12/16 #40 不许掉出 ≥11/12）。

### 3 · 大他者：无条件供养 + 税 + 账本（想法 ③）

**账户**：把现有 `external_coin` 正式命名为**大他者账户**（数据层改名、代码字段保留以免牵连 save schema）。新增三条流，全部经 `transfer`：
| 流 | 方向 | 说明 |
|---|---|---|
| 供养 `supply` | 大他者 → 镇库（货）| 生存货（口粮、柴薪）按"镇库低于地板"定量补到地板，经港口/火车 manifest **物理到货**（沿用 P1-b 卸货机制）；**不要钱**——这就是"无条件"。 |
| 补贴 `subsidy` | 大他者 → town_coin | 镇库现金低于下限时补到下限（上限有界，防通胀）。 |
| 税 `tax` | town_coin → 大他者 | 夜结按设施营收 + 外来者消费的比例上缴（上限 = 当期补贴 + 常数，防通缩：175 §二"构造性平衡"）。 |
| 出口 `export` | 镇 → 大他者（货），大他者 → 镇（钱） | 保留豆子；新增**服务出口**＝外来游客的消费（本质是外部钱进镇）。 |

**账本（ledger）**：
- 所有 `transfer` 已有 `reason` 字符串 + event_log ⇒ **账本是 event_log 的纯折叠**，不是第二份权威态（与 #38 库存可从 event_log 重算同一纪律）。
- **资产负债表 HUD**（纯 View，零金标）：镇库现金、大他者净头寸（累计供养 − 累计税 − 累计出口）、当日收支分类（工资/账单/税/补贴/营收/进出口）、每种货的库存与 30 天进出。一个"镇公所"建筑里也能看到（可点击的账本物件）。
- **目标读数 nx balance**：`净依赖 = 供养 + 补贴 − 税 − 出口`，镇越自给越接近 0。这是一个**读数，不是门**（门会逼着调参让它变绿，175 已吃过这个亏）。

**火车**：新增一条铁路 + 小站（地图边缘，与港口对称），第二个 manifest 节点。货走港口，**人（游客、通勤外来工）走火车**——给外来人群一个到达/离开的物理通道。

### 4 · 百人镇：40 具名 + 60 轻量（想法 ④ + ⑥）

**具名居民 12 → ~40**（全保真：需求、关系、记忆、冲突、欲望）：
- personas 已有 24 张；再补 ~16 张，**要带岗位**（不再是无岗克隆）：新岗位随 §供应链 与 §5 场所出现（面包师、渔夫已有 → 加农夫、磨坊工、奶农、裁缝、理发师、厨子、放映员、邮差、教员…）。
- **房子**：41 栋实体房子里挑 ~15 栋开室内（复用 193 的 furnish 管线 + 模板），每栋 2-3 人。
- **先修 N=40 的已知红**：docs/92 的社交生存门自锁（`_social_candidates` 在 argmin 恰为 social 时关死唯一出口）——**必须在扩人之前修**，否则 40 人就是已知红镇。

**轻量人群 ~60（visitors）**：不是克隆 agent，是**一类新的轻量实体**：
- 状态只有：身份类型、钱包、日程（到达日/离开日/每相位目的地）、当前位置/路径、2 条简化需求（饥/累）。**没有关系/记忆/冲突/欲望**。
- **四类**：
  1. **游客**（夏季多，Rohmer《夏天的故事》）：火车/船到，住酒店 N 晚，逛集市/餐馆/海滩/剧场，花钱 → 营收 + 税，离开。
  2. **外来工**（affiliate）：常驻，住宿舍/酒店，经营 §2 的设施，领工资（大他者付），在镇里消费。
  3. **通勤者**：每天火车来、白天在镇上做工（码头/磨坊）、傍晚走。
  4. **业主/股东**：少数几位，持有酒店/餐馆的产权，每周来一次、住一晚，拿分红（设施营收 → 业主钱包 → 离开时回大他者），交产权税。
- **钱的守恒**：外来者到达时 `大他者 → 外来者钱包`，离开时剩余 `外来者 → 大他者`；中间所有消费经 `transfer` ⇒ #34 不用改，只把外来者钱包加进守恒集。
- **确定性**：到达名单 = `f(data, day, 季节)`，无 RNG；每人 id = `vis_<类型>_<日>_<序>`（沿用 manifest id 的纯函数纪律）。
- **与具名居民的交互**：可以被 greet、可以同桌、会出现在别人的眼里（旁观事件），但**不发起**复杂社交，不结仇。具名居民对"外人"可有看法（一个聚合的 `对外人的态度` 读数，只进语音）。
- **成本**：轻量实体每 tick 只推进路径与日程，不跑候选枚举（候选枚举是 LOD 里最贵的那部分）⇒ 60 个的成本约等于几个全保真 agent。

**供应链 + 货品丰富度**（自给要有东西可产）：在现有 7 货上加两条链，全部是**加法**（不 gate 口粮，吸取 docs/113 里 E3 磨坊链"把口粮 gated 在面粉上 = 饿穿风险"的教训）：
- 小麦（农夫）→ 面粉（磨坊）→ **面包**（面包房，舒适食物、可出口）；
- 鱼（渔夫，已有岗）→ 鱼（鲜货，餐馆用，可出口）；奶（奶农）→ 奶酪；
- 布（外进口）→ 衣服（裁缝）→ 理发/置装类"面子"消费；纸（进口）→ 报纸/话本（邮差/书店）。
- 口粮仍是大他者兜底的**生存货**；新货全是舒适/面子/娱乐层（175 的 Anno 第 ②③④ 层）。

### 5 · 社交生活：Rohmer / Rivette / Demy 式的日子（想法 ⑤）

**场所**（按优先级，每个都是 affiliate 经营 + 收费 + 营业时段）：
| 场所 | 活动 | 片子里的样子 |
|---|---|---|
| 餐馆/小酒馆 | 同桌吃饭（2-4 人），可邀约 | Rohmer 的饭桌长谈 |
| 舞厅/舞会（节日） | 结伴、换舞伴、偶遇 | Demy《罗什福尔的姑娘们》、Rohmer《绿光》 |
| 剧场/电影院 | 定时开场、坐一排、散场后议论 | Rivette 的剧团排练、Rohmer 看完电影去咖啡馆 |
| 读书会（图书馆，每周一晚） | 固定成员、轮流发言 → 一条话题 gossip | Rivette《巴黎属于我们》的秘密读书会 |
| 理发店 | 等位闲聊，出来"面子"加分 | Demy《瑟堡的雨伞》式街角店 |
| 海滩/海堤散步 | 夏季游客、偶遇、换伴 | 《夏天的故事》《海滩上的宝琳》 |
| 家宴/派对 | 居民在自己家请客（邀请名单来自亲近关系） | Rohmer《我女友的男友》 |

**机制**：
- **邀约动作 `invite`**：A 向亲近的 B 发出"某相位在某场所见"的约定（一个新的 commitment，有现成的 commitment/journey 机制可复用）；B 按关系与日程接受/拒绝；到点双方前往。**这是本相位最核心的新动作**——Rohmer 的戏都是"约了、去了、碰见了别人"。
- **活动日历**：festivals.json 的"定日 spawn"机制推广成**周历**（读书会周三晚、电影周五周六晚、舞会节日）；活动是多人同场的 attend 候选（`_attend_candidates` 已有）。
- **偶遇**：同场的第三人（尤其游客）⇒ 现有 greet / 欲望 v0 的模仿中介自然接上（"我想要别人显得想要的人"——Rohmer 的三角恋是它的最佳舞台；欲望 v0 可在这个相位考虑默认开）。
- **季节调子**（Rohmer《四季故事》）：春=读书会/散步，夏=游客/海滩/舞会，秋=收获/集市，冬=剧场/家宴；接现有 weather/季节，改变游客数与活动表。

## 三、不变量契约（在 175 §二之上，本轮新增/改写）

- **#34 守恒集** 扩：town_coin + 所有居民 coin + 大他者账户 + **所有在镇外来者钱包**。外来者离开时钱包必须清零回大他者。
- **#35 非负** 覆盖外来者钱包与欠账（欠账是负债字段、不是负 coin）。
- **#01/#40 生存 floor 不变**：家当空、欠账、没钱都**不许**让 hunger 补不上——只打折上限，且上限打折不低于"生存门 + 余量"。新增一条硬检查：**任何降级补给的上限 ≥ SURVIVAL_GATE + 10**。
- **175 核心规则不变**：困顿/欠账/职业记录/面子**全都不进 `_acceptance_margin` 与生存产者决策**。
- **账本 = event_log 的纯折叠**：HUD 读数必须能从 event_log 重算（同 #38），加一条新的硬检查：账本折叠 == 各账户实时余额。
- **确定性与回放**：外来者到达、邀约、日程全部纯函数，进逐 tick chain；新 Sim 字段逐个判定进 save 或进 `SAVE_LOAD_DENY`（193 的教训）。
- **构造性财政平衡**：税 ≤ 补贴 + 常数；补贴有上限；大他者净头寸有界。**这一条是硬检查**（否则财政螺旋）。

## 五、风险（已知会咬人的地方）

1. **#40 在 N=16 本就踩在 11/12 边缘**（193 实测，master 同样）。P1/P2 任何改变劳动时间分配的机制都会晃它。对策：每相都 diff 逐动作计数 vs master，找根因，不硬调常数（193 的教训：常数微调非单调）。
2. **家当可能重演 193 的"家里什么都有 ⇒ 不出门"**：家当只装生活用品、会用完、要出门买；吃饭的全额补给只在餐馆/面包房（家里是打折版）。P1 必须量"出门次数"不降。
3. **财政螺旋**：税/补贴/账单三条流互相放大。构造性上下限 + 硬检查。
4. **性能**：40 全保真 + 60 轻量。先在 P3 量 N=40 每 tick 成本；轻量实体不跑候选枚举。
5. **规模扩张带来的内容量**：16 张新 persona、~15 个室内、6 类新场所、~10 种新货 sprite——PixelLab 预算估 80-120 次生成，分摊到各相。
