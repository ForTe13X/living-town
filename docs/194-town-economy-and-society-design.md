## 二、设计

### 1 · 产业方向：进口原料，本地做服务（总纲）

今天的镇子是"每样东西本地产"：农夫/面点师/渔夫/伐木/泥瓦匠，劳动力大半在生存产出上，这也是 #40 反复卡边的根源。
新方向把**生存与原料层交给进口**，**本地劳动力上移到服务层**：

| 层 | 今天 | 新方向 |
|---|---|---|
| 生存货（口粮、柴薪） | 本地岗位产出 + 少量进口 | **大他者供养**，经港口定期到货（无条件，§4） |
| 原料/半成品（面粉、酒、布、木料、咖啡豆、纸、鲜鱼的一部分） | 无/本地 | **进口**（港口大宗 + 铁路快件，§6） |
| 本地精加工 | 糕点、屋瓦 | 面包/可丽饼/糕点、海鲜、咖啡、手作——**用进口料做**，是本地的招牌 |
| 服务（主业） | 咖啡馆 | 餐馆、酒店、理发、精品店、游船、海水浴、导览、剧场、画廊…… |

- **本地保留的产出 = 特产**，只挑"与小镇气质相称、游客愿意为之花钱"的。参照 Rohmer 夏日故事的布列塔尼海岸（Dinard/Saint-Malo 一带）：
  | 类 | 特产 | 谁做 / 在哪 |
  |---|---|---|
  | 本地蔬菜 | 洋蓟、新土豆、韭葱、海蓬子（海边盐沼） | 菜农；南部平地的菜园 + 西坡台地梯田 |
  | 本地花卉 | 绣球花（镇花）、海石竹、玫瑰 | 花农 + 花店；花圃；夏季"绣球花节" |
  | 海产 | 贻贝、生蚝、渔获 | 渔夫（北塘渔埠）+ 蚝农（海边蚝床） |
  | 菜肴 | 荞麦饼（galette）、可丽饼、贻贝薯条、海鲜拼盘、黄油酥饼（kouign-amann）、苹果酒 | 餐馆/可丽饼店/面包房的招牌菜，**用本地菜 + 海产 + 进口面粉/黄油做** |
  - 特产是**本地菜单 + 集市 + 花店 + 出口 + 纪念品**的共同来源：游客在餐馆吃、在集市买、离开时带走（记一笔出口）。
  - 菜园/花圃/蚝床是**季节性**的：春种夏收秋收，冬季休耕——接季节调子（§7），也给土著一个非服务业、但与游客经济直接挂钩的工作。
  - 特产**不 gate 生存**：口粮仍由大他者兜底；特产菜是舒适/面子/娱乐层（175 Anno 第 ②③ 层），缺货只落消费者情绪。
- **收入结构**：游客消费 + 度假业主的开销与房产税 → 本地服务业营收 → 工资 → 居民家计；税上缴大他者、大他者供养生存货。
- 这直接给 175 的"affiliate 外营绕开劳动耦合"换了一个更贴用户意图的解：**劳动耦合用进口卸掉，服务由本地人自己做**。
  （外来工仍保留作旺季补员，§5。）

### 2 · 家计：挣钱才能过得好（想法 ①）

**家当（pantry）**：每户一个小库存，只装生活用品：`口粮`、`杂货`（新货：肥皂/蜡烛/油盐）、`糕点`。
- 在家吃饭/洗澡**先扣家当**；家当空 ⇒ 这件事照做（生存不变），但**质量降级**：补给上限打折（例：补到 70 而不是 100）+ 一条"家里没东西了"记忆。
- **购物**：新动作 `采买`，在杂货铺/集市付钱把货从镇库搬进家当。走 `_stock_move` + `transfer`，两条唯一通道都不用改。
- **没钱的兜底 = 大他者配给**：`coin < 配给线` 时可到镇公所领 `救济口粮`（直接进家当，不收钱，记一笔事件）。
  被邻居看见 ⇒ 走现有 wealth gossip 管线（面子成本），**不进 `_acceptance_margin`**。

**账单（bills）**：夜结时每户付固定开销，经 `transfer` 进 town_coin：`水电`（按户）、`炭火`（冬季加倍）、`房租`（已有）。
- **付不起 ⇒ 记欠账 `arrears`**，不阻断任何动作；后果：热水/暖气降级、被知情者议论、欠满 N 天镇公所上门（接现成 `confront` 弧）。
- "必须出去工作"从今天的 `poor_line` 单一阈值，变成**持续的现金流压力**：月入 < 月出 的人自然更常上工。

**作息表（schedule）**：`schedules.json`，按职业给模板、居民可覆写：`dawn 起床/早饭 → day 上班 → dusk 下班/采买/社交 → late 回家 → night 睡`。
- 只作**软偏好乘子**，接现有 rhythm 抑制机制（≤1.0：只推迟非当令的事，不加新吸引力），紧急需求照样打断。
- **休息日**：每 7 天一天，岗位班次关闭 ⇒ 社交场所的自然高峰。服务业岗位**轮休**（旺季周末反而要上班——这也是戏）。

**职业伦理（work record）**：岗位持有人的出勤记录（迟到/缺班/早退，相对日程表班次窗口）。
- 后果只落**工资**（迟到扣 1、缺班不发）与独立的 `work_rep`（只进语音/Story/HUD），**不进生存产者决策**。
- 连续良好出勤 ⇒ 小额奖金（镇库付）。守秩序有正向回路，不只是罚。

### 3 · 镇公所与选举：自己管自己的小镇（想法 ② + 治理）

**镇公所（Mairie）**：新建，**坐落在广场南侧**（今天 x 27-36、y 28-34 的空地，夹在澡堂与工坊之间），正对广场。
由此形成一条法国小镇式的中轴：**火车站（南）→ 镇公所 → 广场 → 教堂 → 海边**。
- 室内：大厅（办事窗口：交税/领救济/查账本）、议事厅（开会/计票）、镇长办公室、公告栏。
- 账本物件（可点开资产负债表）、公告栏（选举结果、政策、下周活动表）。

**选举**：在现有话题投票（elections.json，attitude 即选票、纯函数计票）之上加**选人**：
- **镇长 + 议会（3-5 席）**，任期 28 天。候选人 = 本地土著里声望（standing）与社交度高、且自愿参选的人（persona 带参选倾向）。
- **选民 = 本地土著 + 度假业主**（业主有选票，候选人也可以是业主）。
  两边利益天然不同：业主要低房产税、安静、好海滩；土著要工作、工资、救济与服务——这正是 Rohmer《树、市长与媒体图书馆》的张力，派系（`_recompute_factions` 已有）会沿这条线自然成形。
  业主只在镇上时投票；不在镇的业主可以**委托投票**给一位亲近的人（一个现成的"信任"关系读数）——这本身就是拉票的戏。
- 投票 = 选民对候选人的 `affinity`/`standing` + 对其政纲（话题 attitude）的认同 + **对上一届政绩的评价**（下文），纯函数计票；竞选期有拉票（新社交动作 `canvass`，走现有 greet/gossip 管线）。

**镇长的职责（不只是经济）**：镇长是一个全保真居民，当选后日程里多出**公务时段**（镇公所办公）与一张**职责清单**。每项职责是一组镇长能做的动作 + 一个进政绩的读数：

| 职责 | 镇长做什么 | 政绩读数 |
|---|---|---|
| **维护** | 派环卫/泥瓦匠修屋铺路、修海堤；批维修预算 | 整洁度、屋瓦完好率 |
| **运营** | 定设施营业时段与人手、定收费档、定救济配给线 | 设施开门率、救济领取数 |
| **调解冲突** | 对进入 `confront` 的冲突弧出面调解（接现有冲突弧；docs/113 L3-d 早就留了 mediate 的位） | 调解成功数、积怨弧数 |
| **筹办活动** | 编周历、批节日预算、请剧团/乐队（外来工） | 活动举办数、到场人数 |
| **寻找机会** | 向大他者争取项目拨款、谈新的进出口 lane、招投资（§8） | 新 lane/投资数 |
| **宣传推广** | 花宣传预算 ⇒ 下一季游客到达乘数上调（有上限、有滞后） | 游客人数 |
| **财政** | 定税率/房产税、控制支出 | **赤字**（镇库收支差） |

- **目标函数 = 政绩**：选民在下一届按自己关心的读数给现任打分（业主更看重整洁/海滩/税，土著更看重工作/救济/活动）⇒ 镇长的"最小化赤字"与"多办活动、多维护"天然冲突，要取舍。
- **年度工程**：从候选工程里挑一个用镇库出钱（媒体图书馆、剧场翻修、海堤浴场、铁路站扩建……）→ 完工走现有 `on_pass` WorldPatch 改镇。
- **议会**：否决/通过镇长的预算与工程（简单多数，纯函数计票）；议员也有调解、筹办的职责，是镇长不在时的替补。
- 管理层由选举产生 ⇒ **每任期换人、换政策**；政策改家计与营收 ⇒ 下一届选票。一个自洽的政治-经济回路。
- **防螺旋**：所有旋钮有硬上下限（构造性平衡，§三）；政策只动价格/比例/预算，不动生存 floor；镇长行为是**候选加分**，不硬编码"必须修某处"。

### 4 · 大他者：无条件供养 + 税 + 账本（想法 ③）

**账户**：把 `external_coin` 正式命名为**大他者账户**（数据层改名、代码字段保留以免牵连 save schema）。新增流，全部经 `transfer`：

| 流 | 方向 | 说明 |
|---|---|---|
| 供养 `supply` | 大他者 → 镇库（货） | 生存货（口粮、柴薪）按"镇库低于地板"定量补到地板，经港口 manifest **物理到货**（沿用 P1-b 卸货）；**不要钱** |
| 进口 `import` | 大他者 → 镇库（货），镇 → 大他者（钱） | 原料/半成品（面粉、酒、布、木料、咖啡豆、纸），**付钱**，由商户/镇库按需订货 |
| 补贴 `subsidy` | 大他者 → town_coin | 镇库现金低于下限时补到下限（有上限） |
| 税 `tax` | town_coin → 大他者 | 夜结按营收 + 房产税的比例上缴（上限 = 当期补贴 + 常数） |
| 服务出口 | 游客/业主 → 镇 | 本质是外部钱进镇：到达时从大他者带入钱包，在镇上消费（§5） |
| 货物出口 | 镇 → 大他者 | 保留豆子；加渔获、糕点等"小镇特产" |

**账本（ledger）**：
- 所有 `transfer` 已有 `reason` + event_log ⇒ **账本是 event_log 的纯折叠**，不是第二份权威态（与 #38 同一纪律）。
- **资产负债表 HUD**（纯 View，零金标）：镇库现金、大他者净头寸、当日收支分类（工资/账单/税/补贴/营收/进出口/房产税）、每种货的库存与 30 天进出、游客人数。镇公所的账本物件可点开同一张表。
- **读数 nx balance**：`净依赖 = 供养 + 补贴 − 税 − 出口`。服务业镇的自给 = 游客与业主带进来的钱 ≥ 进口 + 供养的价值。**是读数不是门**。

### 5 · 三类人：本地土著、度假业主、游客与外来工（想法 ④ + ⑥）

| 类 | 数量 | 保真度 | 住哪 | 钱从哪来 / 到哪去 |
|---|---|---|---|---|
| **本地土著** | ~36-40 | 全保真（需求/关系/记忆/冲突/欲望/选票） | 镇里的房子（租或自有） | 服务业工资 → 家计开销 |
| **度假业主**（大城市居民） | ~8-12 户 | **全保真，但季节性在场**（夏季长住、周末偶来）；**有选票** | 自有别墅/宅邸（西坡上城 + 海边宅邸） | 带钱进镇 → 雇本地人、投资、租出店面/短租别墅、消费、存银行、交房产税；不在时仍交税 |
| **游客** | 旺季 ~40，淡季 ~5 | 轻量 | 酒店 | 到达带钱 → 酒店/餐馆/精品/游船 → 离开余额回大他者 |
| **外来工**（旺季补员） | ~5-10 | 轻量 | 宿舍/酒店员工房 | 大他者或雇主付薪 → 部分在镇消费 |
| **通勤者** | ~5 | 轻量 | 不住，火车来回 | 同上 |

- **全保真总数 ≤ 60**（40 土著 + ~12 业主，业主不在时不计入每 tick 成本）⇒ 175 的"≤60"红线**精神上保留**。
- **业主是 Rohmer 的主角**（巴黎来度假的人）：他们与本地人的阶层差、雇佣关系、夏日恋情是社交层的核心戏剧。
  业主的"钱多、无选票、季节性"三点，天然接上 §3 选举与 §7 社交。

### 6 · 铁路：人走火车，货走海（想法 ③ 的运输逻辑）

### 8 · 银行与商业：租赁、投资、雇佣（想法 ③ + 用户补充）

**镇银行（Caisse）**：新建，**紧挨镇公所**（广场南侧同一排，用户 2026-09-13 定）。一个**有自己账户**的机构，进 #34 守恒集。
- **资本金**：开业时由大他者注资一次（一笔 `transfer`，大他者 → 银行）。
- **存款**：居民/业主把钱存进银行（`transfer` 居民 → 银行，记存款余额），按周付小额利息（银行 → 居民）。
- **贷款**：开店、买房、翻修、业主收购宅邸；按周还本付息。**全额准备**：贷款总额 ≤ 存款 + 资本金 − 已贷，**银行不凭空造钱** ⇒ #34 一个字节不用改。
- **违约 = 困顿不挨饿**：还不上 ⇒ 欠账 + 信用降级（不能再借）+ 被议论；抵押物（店铺租约/房产）可被银行收回、镇公所拍卖。**生存 floor 不受影响**。
- 银行利润（贷款利息 − 存款利息）的一部分交税。银行本身由一位土著经理 + 柜员经营（服务岗）。
- 用处：让"开一家店""买一栋房""业主投资"这些大额事件有了钱的来路——没有银行，个人钱包永远攒不到开店的数。

**产权登记册**：把 housing.json 的租约、buildings.json 的 `owner`（今天"只存不计租"）统一成一张**产权登记册**：每栋房子/每间店铺有产权人（土著/业主/镇/银行），产权变更只经登记（一条 `deed` 事件）⇒ 可从 event_log 折叠重算。

**租赁（lease）**：
- 店铺租约：镇或业主把店面租给土著开店，按周收租（今天的 `rent` 推广到店铺）。
- 住房租约：已有（8 对）；业主不在镇时可以把别墅**短租给游客**（酒店之外的第二种住宿，营收进业主钱包、交税）。

**投资（investment）**：
- 业主（或有钱的土著）出资入股一家店/餐馆/酒店翻修 ⇒ 按份额拿分红（营收 → 投资人钱包，夜结）。
- 镇长的"寻找机会"职责可以招来外部投资人（一类轻量外来者：来一趟、签约、走，按季收分红）。
- 投资失败（店关门）⇒ 本金亏掉（钱留在已花掉的地方，守恒不破）。

**雇佣（hire）**：
- 业主雇本地人做管家/园丁/厨子（工资从业主钱包出，按周）。
- 店主雇伙计（今天的岗位工资由镇库付，改为**雇主付**的那部分岗位从店营收出）。
- 旺季雇外来工。
- 雇佣关系是一条关系边（雇主—雇员），接现有 relationships：拖欠工资 ⇒ 积怨 ⇒ 冲突弧 ⇒ 镇长调解。

**这些都是 Rohmer 的戏**：业主与管家、借钱开店的年轻人、为收购海边宅邸而竞价的两个外来者。

## 三、不变量契约（在 175 §二之上）

- **#34 守恒集** 扩：town_coin + 所有居民与业主 coin + 大他者账户 + **银行账户** + **所有在镇外来者钱包**。外来者离开时钱包清零回大他者。
- **银行全额准备**（硬检查）：银行现金 ≥ 全部存款负债；贷款只来自存款以上的合作社资本。现金、存款与贷款应收均可从 event_log 折叠重算。
- **产权唯一**（硬检查）：每项产权任一时刻恰有一个产权人；产权人 == `deed` 事件折叠结果。
- **#35 非负** 覆盖外来者钱包；欠账是负债字段、不是负 coin。
- **#01/#40 生存 floor 不变**：家当空、欠账、没钱都不许让 hunger 补不上。新增硬检查：**任何降级补给的上限 ≥ SURVIVAL_GATE + 10**。
- **175 核心规则不变**：困顿/欠账/职业记录/面子/政治立场**都不进 `_acceptance_margin` 与生存产者决策**。
- **账本 = event_log 的纯折叠**：新增硬检查"账本折叠 == 各账户实时余额"。
- **确定性与回放**：外来者到达、邀约、日程、计票、政策全部纯函数，进逐 tick chain；新 Sim 字段逐个判定进 save 或 `SAVE_LOAD_DENY`（193 的教训）。
- **构造性财政平衡**（硬检查）：税 ≤ 补贴 + 常数；补贴有上限；政策旋钮有硬上下限；大他者净头寸有界。

## 五、风险

1. **#40 在 N=16 本就踩在 11/12 边缘**。P2 的进口转向是松开它的正路，但转岗过程中会晃；每相 diff 逐动作计数 vs master 找根因，不硬调常数。
2. **家当可能重演 193 的"家里什么都有 ⇒ 不出门"**：家当只装生活用品、会用完、要出门买；全额补给只在餐馆/面包房。P1 必须量"出门次数"不降。
3. **财政/政治螺旋**：税、补贴、账单、政策四条流互相放大。构造性上下限 + 硬检查；政策只动价格/比例。
4. **服务业把劳动重新耦合进来**：服务岗由土著做（用户意图），会重开 E4c/E4d-B 的劳动纠缠——对策是 P2 先用进口把生存岗卸掉，服务岗占的是**被释放出来的劳动时间**。每相量岗位在班完成次数。
5. **性能**：40 土著 + ~12 业主 + ~50 轻量。P5 量 N=40 每 tick 成本；轻量实体不跑候选枚举。
6. **银行与贷款是新的放大器**：贷款让个人一次性花大钱 ⇒ 财富分化更快、违约连锁。全额准备 + 单笔贷款上限 + 违约只落困顿/信用，不落生存。
7. **镇长职责可能变成"第二个 fun 条"**：每项职责要量**实际做了多少次、政绩读数有没有被它改变**（欲望 v0 同一条消融验收）。
8. **内容量**：~16 张新 persona、~15 个室内、别墅若干、镇公所、银行、车站、货场、菜园/花圃/蚝床、5+4 类场所、~15 种新货与菜肴 sprite——PixelLab 预算估 150-200 次生成，分摊到各相。
