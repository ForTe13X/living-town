# Opt-in original worker assembly

This development path installs the original Tripo worker in the existing café Ben pawn. The body owns ordinary idle/walk animation, a shared-skeleton support follows it, and one Chaos apron supplies the visible garment. Movement, camera controls, café authority and paired saves retain their existing owners. Default presentation is unchanged.

Use the qualified WorldV3 café project/content with its exact GameMode and add:

```text
-LivingTownCafeWorldV3 -CafeWorldPersona=ben -LivingTownOriginalWorkerBen="<prepared-directory>/PREPARED_BINDING.json"
```

The GameMode is `/Script/LivingTownNative.LivingTownCafeWorldV3GameMode`. The descriptor is generated by the Editor preparation function, not authored as an approval flag. Missing/malformed descriptors or incompatible skeleton, material, motion, socket or existing component state refuse configuration. The default café still refuses physical eating without its separately reviewed provider; animation alone grants no meal or care benefit.

## Asset boundary

`LivingTownOriginalWorkerPreparation.prepare_original_worker_ben(calibration_path, report_directory)` creates four owned packages under `/Game/LivingTown_UEPilot/OriginalWorkerBen_v001`: `SK_Ben`, `A_Idle`, `A_Walk`, and `BS_IdleWalk`. Preparation requires the explicit `-LivingTownPrepareOriginalWorkerBen` Editor flag and measured calibration inputs.

The producer preserves the eighteen source packages, original sixty-one animated tracks, curves, attributes and timing. Only constant translations on the added unweighted wrapper normalize the two clips. The mesh-owned palm socket uses the measured REST hand inverse; offsets from the earlier sixty-one-bone family are incompatible. Use the factory's original descriptor bytes, since its digest also identifies the prepared visual in saves.

The current local consumer stages those eighteen source and four derived packages. Assets and calibration are external development inputs; this source PR does not include or manufacture a finished character bundle. ChaosClothAsset and ACLPlugin are enabled. A future selected cook must explicitly include the string-loaded support, apron and physics packages plus the engine `GrayTextureCube`; derived-animation dependencies alone do not establish a complete cook.
