# 223 · P4c-5 政绩改投回执

> 接 [222](222-p4c4-performance-vote.md)：政绩已经进入连任选票，但结果播报只说谁当选，玩家无法判断这份成绩究竟改变了几张票。

每次镇长选举现在同时计算两只票箱：真实票箱使用现行的 `standing + 上届政绩`，反事实票箱只使用 `standing`。两者逐选民比较，得到政绩造成的改投总数，以及前任因此得到和失去的票数。反事实计算复用同一个稳定投票函数，不消耗随机数，也不反向改变任何关系、需求、钱或日程。

回执附在本届 `election(note=mayor_term)` 事件上：`baseline_ballots`、`performance_swings`、`incumbent_gained`、`incumbent_lost`、`review_event_id_used` 和 `incumbent`。大事栏只在确有改投时追加“政绩改投 N 票（前任 +G/−L）”；没有改投时保持原来的短句。

硬不变量 #37 逐届核对：反事实票箱总票数等于合资格选民数，候选键合法，改投数等于得票与失票之和，前任真实票数等于反事实票数加得票减失票，并且事件与任期记录引用同一张成绩单。没有成绩单参与时，反事实票箱必须与真实票箱完全相同且改投数为零。
