## 〇、判决（先说结论，证据在后面）

**外审批准的第一刀是「domain-scoped `KnowledgeState`：B 镇在消息到达前，权威决策代码确实无法读取 A 镇那件事」。
实测：这条性质在 belief 层【今天已经逐字节成立】——而在【派系层】它今天就是破的，
且破的方式恰好是外审描述的那一种。⇒ 第一刀的方向对，落点要移一层。**

四句话：

1. **belief 层的知识边界是真的，而且是逐字节的。**
   往世界里塞一条**只有一个人知道、且那个人讲不出去**的事实，全镇 30 天**逐字节不变**——
   `chain` / `Inv.digest` / `event_digest` / 事件条数四项逐位相同，逐 agent 指纹 0/N 分叉。
   **N ∈ {12, 20, 60} × seeds {1, 5, 13} 全格如此**（§二）。
   **负对照**（同一条惰性事实 + 一个蓄意植入的"全镇有没有人知道"全局读）**在同一格上当场分叉**，
   且最早跟着变的是**与知情者毫无接触的旁人**——那正是"provenance 装饰"的指纹。
2. **但派系层不是。** 只改**一个人的私有立场**（`attitudes`，谁都看不见、没有任何事件），
   **在【下一个日界】就有四个别人的 `faction` / `faction_size` 跟着变**——
   而那时**全世界的行为还逐字节没动**（N=12 seed 1：改动@1200 → 派系@**1440** → 首个行为分叉@**1502**；
   seed 5：1200 → **1440** → **1533**）。其中 `tie` 从 `lin/2` 掉成 `/1`，
   **整条 `endorse` / `rally_oust` 候选支与 `_faction_term` 接受加成当场消失**，
   而它与 lin 之间**没有发生任何交互、没有一条事件、`event_log` 里一个字都没有**（§四）。
   ⇒ **`_recompute_factions()` 每夜从【全镇每个人的私有 attitudes】重算，没有任何空间/知识门。**
3. **外审那条否决条件成立了。** 三臂对照（全部在**一个镇**里做）：
   **具名 carrier 与匿名延迟消息，`chain`/`digest`/`event_digest`/不变量/归责结果逐位完全相同**
   （ARM2 ≡ ARM3，N=12/20/60 全格）。机制是结构性的：**`belief.source` 在决策路径上零引用**（§1.6）。
   ⇒ *"若具名 carrier 相比匿名延迟消息没有改变任何权威行为、关系或归责结果 ⇒ ①的产品理由应被否决。"*
   **按今天的实现，它被否决了。**
4. **但这条否决要读准，别读成"载体没有价值"。**
   ARM4（消息真的靠 `gossip` 事件一跳一跳传）与 ARM2/3（凭空写进每个人脑子）**差别巨大**。
   ⇒ **载体的社会价值 100% 在【那次搭话】里，0% 在【provenance 字段】里。**
   想让"谁带来的消息"真的有分量，要做的**不是**记 `source`，是让 `source` 进入某条**权威判据**（§六）。

**⇒ 对 docs/62 §四的直接修正**：它说这一刀"可能比第二张地图昂贵得多，而且它是先决条件"。
**先决条件那半句对；"昂贵"那半句在本仓库不成立，而"它在 belief 层"那半句是错的——
belief 层白拿，要花钱的是 attitude→faction 层与三个非知识的全局读（§1.4）。**

## 一、① 权威决策到底读什么——逐条读清单

口径：**"权威" = 会改变 `Inv.chain_step` / `Inv.digest` 的那条路径**，即
`agent_candidates`（4 个枚举器）→ `_logic_decide` 打分 → `agent_apply` → `_commit_social` 的 `_acceptance_rule`，
外加每日 `_nightly()`。每条标注**局部（只读自己）/ 跨主体（读别人的私有字段）/ 公共（世界事实）/ 全局（全镇聚合）**。

### 1.1 `_object_candidates`（物件候选，`Sim.gd:1739`）

| 输入 | 出处 | 性质 |
|---|---|---|
| `ag.needs[*]`、`ag.pos`、`ag.space/floor`、`ag.inventory.coin`、`ag.home_needs`、`ag.skills` | 自己 | 局部 |
| `world.objects[*]`（**先按同 space/floor 过滤**） | 世界 | 公共 |
| `_staff_ok(ag,o)`、`adv.job` vs `_job_of(ag.id)` | 自己的岗位 | 局部 |
| `tod` / `weather_today` / `season_today` | 全局环境 | 公共（天气看得见） |
| **`_market_open(action)`** → `_holder_of_title(vendor.title)` + `_in_shift(_job_of(vid))` | **全局 jobs 表** | **全局** ⚠ |
| **`_clean_mult()`** → `_stock_of("整洁") / cap` | **全镇库存** | **全局** ⚠ |
| **`work_pull_mult`** → `f(agents.size())`（`start_new` 时冻结） | **全局人口** | **全局** ⚠ |
| `_wage_for(ag,action)` + `economy.poor_line` | 自己钱包 + 数据表 | 局部 |

### 1.2 `_social_candidates`（社交候选，`Sim.gd:1837`）——跨主体读全在这里

| 候选 | 读到的【别人的】私有字段 | 门 |
|---|---|---|
| greet / give / invite | 无（`_rel(ag,o)` 是**我自己**的账本） | — |
| **gossip** | **`o["beliefs"]`**（`_unspread_belief:3414` 的 `not target["beliefs"].has(cid)`） | `_nearby_agents` |
| **confide / leak** | **`o["beliefs"]`**（`:3949` / `:3955`）+ `_secret_private` 扫**全镇 pos**（EARSHOT） | `_nearby_agents` |
| **discuss** | **`o["attitudes"][t]`** | `_nearby_agents` |
| **gossip_rep** | **`_rel(o, C)["standing"]`**（对方对第三方 C 的私有印象） | `_nearby_agents` |
| **endorse** | 同上 **＋ `_agent_by_id[C]["faction"]`（C 可以完全不在场）** | `_nearby_agents`（对 o）／**无**（对 C） |
| **aid** | **`o["needs"][*]`** | `_nearby_agents` + active pact |
| 同派系日常亲和 / rally_oust | `o["faction"]`（**每夜全量重算的派生量**，见 §1.2b） | `_nearby_agents` |
| confront / apologize | `conflicts` 全局数组，**按 (a,b) 双向过滤** | `_nearby_agents` |
| attend | `commitments`，**按 `c.a/c.b == 自己` 过滤** | — |

> **在候选生成这一层**，除了 `endorse` 读 C 的 `faction` 那一处，**每一条跨主体读都在
> `for o in _nearby_agents(ag)` 的循环体内**，而 `_nearby_agents` 的判据是
> **`_same_plane(o,ag) and o.area == ag.area`**。
> ⇒ **引擎允许你"看穿站在你面前那个人的心思"，但不允许你看穿一个不在场的人。**
> 这是**空间**局部而不是**知识**局部——但对多镇提案而言，它给的保证正好够用：
> 另一个镇的人天生不在 `_nearby_agents` 里（`_area_key` 对非-town 返回 `"space:floor"`）。
>
> ⚠ 诚实边界：这条保证**不是**一道门在守，是**一个循环的形状**。今天没有任何断言禁止有人在
> `_social_candidates` 里加一行 `for x in agents:`。**要把它变成契约，需要的是一道门，不是一次重构。**

### 1.2b ⚠ 夜间层：三处**没有任何空间门**的跨主体访问

上面那句话只对候选生成成立。往上走一层，`_nightly()` 里有三处完全没有空间门的跨主体读写。
**这一节是本棒对自己 §1.2 结论的自我更正，也是 §四 那条实验的靶子**：

| 位置 | 干了什么 | 为什么它是知识局部性的洞 |
|---|---|---|
| **`_recompute_factions()`**（`Sim.gd:3885`） | 每夜用 `_aligned(a,b)` 逐对比较**全镇每个人的私有 `attitudes`** 做 medoid 聚类，写回 `ag["faction"]` / `ag["faction_size"]` | **零空间门。** 从未谋面、甚至不同平面的人可以同派系；而 `faction` 直接进**候选生成**（endorse / rally_oust / 同派系亲和）**与接受判定**（`_faction_term`，权重 ±`FACTION_ACCEPT_K`）⇒ **一个人的私有立场隔着整个镇改变了另一个人的权威决策。§四已实测。** |
| **`_form_pacts_greedy()`**（`Sim.gd:4041`） | 逐对读 **`_rel(o, id)["trust"] / ["affinity"]`**（**对方的**账本）给全镇配对结盟 | 同样零空间门。`PACT_FAM_TH` / `complementSeen` 门要求过去有过接触，所以**结果**大致合理，但**评估过程**是全镇 O(N²) 的私有账本读 |
| **`_resolve_rally_oust()`**（`Sim.gd:3923`） | 对 `factions[fac]` 的**每一个成员**（不管他在哪）调 `_judge_actor(m, o, false, …)` | **写侧**的洞：不在场的派系成员会因为一场自己没看见的合围而改变对 o 的 standing |

### 1.3 接受判定 `_acceptance_margin`（`Sim.gd:3293`）——结构上就是局部的

它读的**每一样都是 target 自己的**：`_rel(target, actor.id)`、`target.needs.social`、
`target.persona.traits`、`_faction_term(target, actor)`、`_rng_at(31, _aid(target))`。
`actor` 只贡献 `actor["id"]` 与（discuss 一条）`actor["attitudes"][subject]`。
⇒ **"接受与否由 target 判、且只读 target 自己的东西"**——本仓库最干净的一处知识边界。
唯一的外置口是 `ext.accept_delta`（L7 挂点）——**本棒的负对照正是从这里进的**。
⚠ 但注意 `_faction_term` 读的 `faction` 本身是 §1.2b 那个全局派生量 ⇒ **这处"干净"是有条件的。**

### 1.4 三个与知识无关的全局读（实测都在动，不是死代码）

每 60 tick 采样一次，30 天：

| 全局读 | N=12 s1 | N=20 s1 | N=60 s1 | 多镇会怎么撞上它 |
|---|---|---|---|---|
| `_market_open`（摊位对外广告位在不在） | **关 90/120** | **关 90/120** | **关 90/120** | 全镇 `jobs` 只有**一个**商贩。两镇共用 ⇒ **B 镇居民瞬时"知道"A 镇商贩下班了**——这才是真正的全局事实表 |
| `_clean_mult()` | `[0.700, 0.850]` | `[0.734, 0.952]` | `[0.770, 1.000]` | `town_stock["整洁"]` 是**一个**数。两镇共用 ⇒ A 镇脏了，B 镇广场的活动当场打折 |
| `work_pull_mult` | **1.000**（结构性短路） | **1.200** | **1.400** | 它吃 `agents.size()`。区域 100+ ⇒ **每个 20 人小镇都会按 100 人去调工作吸引力** |

⇒ **这三条都不在 belief 层，而它们比 belief 层更全局。**

### 1.5 `event_log` 在决策路径上**零引用**

`Sim.gd` 里 `event_log` 一共 3 处代码（`:330` 声明、`:728` clear、`:3430` append）加一处导出（`:1098`）。
**没有任何一处决策/打分/接受读它。** ⇒ 外审担心的"决策时仍能读取全局事件"，**在本仓库不存在**。

### 1.6 `belief.source` 在决策路径上**零引用**

写 4 处（`_commit_social` 的 gossip / confide / leak + `_observe_wealth` / `_shortage_fallout` 的 `"__seen__"`）。
读 3 处：`Invariants #5`（只**报告**扩散跳数，不参与判定）、`Invariants #6`（provenance 判据）、
`Main.gd:1814`（UI 显示）。**决策路 0 处。** 这就是 §三 ARM2 ≡ ARM3 的机制解释。

## 二、② 实验：一条只有一个人知道的事实

### 2.0 为什么本仓库的 A/B 差异集**恰好等于因果锥**（先说清楚，否则数字不可读）

`_logic_decide` 的平局抖动盐取自候选的**稳定身份** `_cand_salt(c)`，而 `_rng_at` 是**无状态**的
（由 `(seed, tick, salt, who)` 纯播种）。⇒ **给 A 的候选表多加一条候选，不会扰动 A 其它候选的掷骰，
更不会扰动 B 的任何一次掷骰。** `_acceptance_margin` 的抖动同理（`_rng_at(31, _aid(target))`）。
⇒ 两臂之间**没有 RNG 流错位造成的假分叉**，凡是分叉都是真因果。
**这是本棒能下"逐字节"判决的前提**，也是它比一般 A/B 锋利的原因。

### 2.1 臂的设计（第 5 天开头 tick 1200 注入 `beliefs["P1FACT"]`）

| 臂 | 注入 | 预期 |
|---|---|---|
| `CTRL` | 无 | 基线 |
| `EXT_NULL` | 无；但挂一个恒返 `0.0` 的 `AcceptanceModifier` | **必须 ≡ CTRL**（证明挂点本身零扰动） |
| `STIFLED_1KNOWER` | 只给阿丽一条，**并置 `stifled`** ⇒ `_unspread_belief` 直接 `continue` ⇒ 对**知情者自己**也惰性 | 若仍分叉 ⇒ 有人越界读了它 |
| `STIFLED+GLOBALREAD` | 同上 **+ 一个蓄意的全局事实读**（`ext.accept_delta`：只要**镇上有人**持有 P1FACT 就 +100） | **必须分叉**（负对照） |
| `KNOWN_1KNOWER` | 只给阿丽一条，**不** stifle | 预期分叉（她自己多一条候选） |

### 2.3 归因：最早跟着变的是谁？（这一节才是判决的牙）

探针对每臂报"最早分叉那一 tick 有哪些人跟着变、他们当时知不知道、
以及**知情者当时在跟谁说话（本臂与对照臂都看）**"。

| 臂 | 最早分叉 | 第一批变的人 | 知情者当时的接触 |
|---|---|---|---|
| `KNOWN` N=20 s1 | @1458 | `aria[知情]`、`tie[不知情]` | aria 本臂 `evy` / 对照 `tie` ⇒ **tie 变了是因为阿丽本来要找她、现在改找 evy 了** |
| `KNOWN` N=20 s5 / s13 | @1272 / @1301 | **只有 `aria[知情]`** | — |
| `ARM2/3` N=20 s1 | @1232 | `fei[知情]`、`npc_16`、`npc_18` | fei 本臂 `npc_16` / 对照 `npc_18` ⇒ **两人正是 fei 的新旧搭话对象** |
| **`STIFLED+GLOBALREAD`** N=20 s1 | @1233 | `hai[不知情/**与知情者无接触**]`、`tie[同]` | aria 本臂 `dan` / 对照 `dan` ⇒ **知情者一动没动，而两个跟她无关的人变了** |
| **`STIFLED+GLOBALREAD`** N=20 s5 / s13 | @1201 / @1203 | `npc_12`+`npc_13` / `dan`+`tie`——**全部"不知情 + 与知情者无接触"** | 同上 |

⇒ **"不知情、且与知情者无任何接触（连反事实接触都没有）的人先动了"= 越过知识边界的读的指纹。**
它**只在蓄意植入全局读的那一臂出现**（N=20 的 3 个 seed 全部出现）。

⚠ **诚实边界**：这条指纹**不是 100% 灵敏**。N=12 s1 的 `GLOBALREAD` 臂最早分叉是
`aria[知情] + tie[被知情者搭话]`——**指纹没出现，但轨迹照样分叉**（事件数 1484 vs 1667）。
⇒ **判红靠的是 chain/digest，指纹只是归因辅助。别把归因指纹当门用。**

### 2.4 一个附带发现：`Inv.chain_step` 有时比真实行为分叉晚一个会话

`chain_step` 折的 option 签名是 `kind|target|partner|area|phase|remaining`——**不含 `action`、不含 `subject`**。
⇒ 会话进行中它分不出"跟 ben 打招呼"与"跟 ben 说 coco 的传闻"。
实测（`analysis/p1/s1_n20_d3.txt`，注入 @240）：`KNOWN` 臂逐 agent 指纹（补了这两项）报 **@245**，
`chain` 报 **@255**——**差 10 tick，恰好是 `CONVERSE_TICKS`**。
⚠ 这个差**不恒定**：30 天档（注入 @1200）两者都报 **@1458**，差 0——因为那次阿丽换的是**搭话对象**，
而 `partner` 在 chain 的签名里。⇒ **只有"同一个人、换了个动作"这一类分歧会被推迟一个会话长度。**
**这不是漏洞**（事件那一半最终会抓到），但排查首个因果分歧点时要知道。

## 三、③ 外审的三臂对照（全部在【一个镇】里做，一张新地图都没有）

把镇按 `agents` 数组前/后半切成两个 cohort（"A 镇"含载体阿丽、"B 镇"另一半）。
**它们物理上仍在同一个镇、同一个 `tick` 循环、同一个 `agents` 数组**——正是 N1 §1.3 推荐的形状。

| 臂 | 谁在什么时候知道 | `belief.source` |
|---|---|---|
| **ARM1 即时全局事实** | 全镇，tick 1200 | `__seen__` |
| **ARM2 匿名延迟消息** | A 侧 @1200，B 侧 @1680 | `__anon__` |
| **ARM3 具名 carrier 延迟消息** | A 侧 @1200，B 侧 @1680（**与 ARM2 逐 tick 逐人完全相同**） | **`aria`** |
| **ARM4 真·载体传递** | 只有阿丽 @1200，其余靠真实 `gossip` 事件 | `aria`（引擎自己写的） |

## 四、④ 派系层：知识局部性今天就是破的（本棒最重要的一节）

**干预**：tick 1200，只把**一个人**（`lin` / N=20 时是 `qin`）的私有 `attitudes` 与天生锚 `attitude0`

**实测（N=12，两个 seed 逐字复现）**：

| | seed 1 | seed 5 |
|---|---|---|
| 干预 | tick **1200** | tick **1200** |

**这三个数的顺序就是判决**：`1200 → 1440 → 1502`。
在 tick 1440 那一刻，**整个世界（包括 lin 自己）的行为还与对照逐字节相同**
（首个分叉在 1502），所以**在 1200 与 1440 之间不可能发生任何一次把 lin 的新立场传出去的 `discuss`**。
⇒ **四个人的派系归属被改变了，而改变它的是一次【没有人观察到的私有心理变化】。**

后果不是装饰：`tie` 从 `lin/2` 掉成 `/1` ⇒ `faction_size < FACTION_QUORUM` ⇒
**整条 `endorse` / `rally_oust` 候选支消失，`_faction_term` 的 ±`FACTION_ACCEPT_K` 接受修正也消失。**
`tie` 正是 seed 1 里最早分叉（@1502）的两人之一。

**对照**：`MINDREAD_STANDING` 臂（只改一个人对第三方的私有 `standing`，同样零事件）

⚠ **诚实边界（必须写清楚，否则这一节会被读得比它硬）**：
- **N=20 s1 上这条链没有这么干净**：别人的派系字段要到 @3360 才变，而行为分叉在 @1934
