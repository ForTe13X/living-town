# 111 · 真机回执——**两件"只有用户能做"的事，今天做了**

> 触发：无线调试恢复（`Pair(449874, 192.168.1.127:45557)`，2026-08-06）。
> 设备 `NX789J`，包 `com.forte13x.livingtown`。
> ⚠️ **本文只报实测，不报推断。**

## 〇、这两件事挂了整整一个 session

从 Wave Q 到 Wave AC，每一轮小结里都写着同一句：
> **"没有人听过音频；没有人在真机上按过触摸操作栏。"**

它们不是被遗忘的，是**结构上只有真机能回答**的（`docs/41` 反复记过：桌面软渲不作数）。今天设备回来了。

## 一、连上设备本身就有一条发现

`adb pair` 成功，但 **`adb mdns services` 返回空**、配对端口 `45557` 连接被拒。
⇒ 连接端口与配对端口不同，且 mDNS 在本机网络下不工作。
**用 TCP 扫描 30000-50000 找到实际连接端口 `42839`**（PowerShell 异步 ConnectAsync，批 500、350ms 一批）。
⇒ **记下来给下一次**：`adb mdns services` 空不代表设备不可连；直接扫端口。

## 二、音频：**在响，而且它根本没有音频文件**

`adb shell dumpsys audio` 的 players 段：
```
piid:5215  type:OpenSL ES AudioPlayer (Buffer Queue)  u/pid:10510/27963
           state:started  sampleRate=44100  channelMask=0x3(立体声)
```
`pid 27963` = Living Town。**状态 `started`，44.1kHz 立体声，正在出声。**

⚠️ **而仓库里 `.ogg`/`.wav`/`.mp3` 的数量是 0**（`find game -iname ...` 实测），
而 `game/scripts/Audio.gd` 有 **464 行**。
⇒ **音频是纯代码合成的，没有任何采样素材。**

**这条改变了那句话的含义**："没人听过音频"此前读起来像"有一批音效没人验收"；
实测是**从来就没有样本，只有一个没人确认过在不在跑的合成器**。**它在跑。**

⚠️ **仍然没做到的**：我没有耳朵。**"好不好听"这一档仍然只有用户能判。**
但"有没有东西可听"这一问，今天从未知变成了**已知：有**。

⚠️ 另一条实测：`dumpsys audio` 的 **audio focus stack 是空的**，
且历史 focus 请求里**没有一条来自本包**（只有 Apple Music 与斗鱼，且都是几天前的）。
⇒ 本应用**不请求音频焦点**就直接出声。**这不是 bug 的证据，但它意味着**：
别的应用在放音乐时，本应用不会让路、也不会被让路。**要不要改是产品决定，不是本文的判断。**

## 三、触摸：**能用，而且比"能不能用"更值得报的是【操作栏在骗人】**

### ① 静态 UI 按钮：可用

点右上「详情」⇒ 变成「收起」，右栏出现 `观察台 Observatory`。**touch 在 UI 层是通的。**

### ② 点居民：**可用**（第一次没中，是因为居民在走）

第一次点空了 —— 而**原因值得记**：截图与点击之间隔了约 3 秒，**居民走开了**。
⚠️ **这本身就是一条真机可用性发现**：见 §③。
在广场附近连点四下之后命中，观察台完整显示：
人设 / 当前动作 / 钱 / 职业与班次 / 五条需求 / 关系（带符号的亲密与怨气）/
冲突 / 故事弧 / 近期记忆。**它是通的，而且信息量很大。**

### ③ ⚠️ **最值得报的一条：底部那条操作栏，在手机上有九分之七是假的**

真机原文照抄：
> `时间轴: 拖动回放（确定性重演）· 空格暂停 · , . 单步 · [] 跳天 · Tab 切角色 ·`
> `Home 回全镇 · L 跟随 · V 详情 · J 纪事 · O 设置 · F5/F8 存读档 · 点居民查看`

逐条判：
| 提示 | 手机上 |
|---|---|
| 拖动回放 | ✅ 可触摸 |
| 点居民查看 | ✅ 可触摸（本文实测） |
| 空格暂停 · , . 单步 · [] 跳天 · Tab 切角色 · Home 回全镇 · L 跟随 · V 详情 · J 纪事 · O 设置 · F5/F8 | ❌ **全部要键盘** |

⇒ **11 条提示里 9 条在这台设备上按不出来。**
而其中 **`空格暂停` 的缺失是有连锁后果的**：没有暂停，居民一直在走，
**§② 第一次点空正是这个的直接结果**。⇒ **"没法暂停"不是缺一个便利，是让"点居民"这个核心交互变难。**

⚠️ **本文不提修法**：这是 UI/UX 设计决定（要不要出触摸按钮、放哪、遮不遮地图），
按 `docs/41 §0.8` 属于该先评审的那一类。**本文只把它从"没人试过"变成"实测如此"。**
