## 一、K1 · 产出侧换尺度（**digest 必动，走 R12**）

**owns**：`game/scripts/Sim.gd`、`game/data/production.json`、`game/bench/Invariants.gd`
**不得触碰**：`game/scripts/WorldView.gd`、`tools/**`、`game/assets/**`

### 要做的事，一句话

**消耗侧一个字不动**（60 个 agent 逐个真算，谁吃了什么、谁缺了什么、缺了记恨谁——全保留）。
**产出侧从"逐个岗位逐笔记账"换成"宏观池"**：池随人口/岗位规模给出供给，
而**不是**让一个泥瓦匠在 60 人镇里神奇地干出 5 倍的活。

### §0.5 写死的两条边界（**违反即作废**）

1. **这不是"放弃 60 人的经济"。** 供给**必须跟得上人口**，缺货**必须仍然有社会后果**。
   降的是**记账粒度**，不是**保证本身**。
   ⇒ **验收里必须有：N=60 时屋瓦不再全年断供。** 做不到就是没做到，不许写成"已降级"。
2. **`#40` 的分档按【模拟契约】，不按【人口】。**
   不是 `if N > 16: 放过`，而是按产出走"逐笔"还是"宏观池"选对应判据。
   **按人口分档 = 给出货配置预埋一条永不变红的门**——评审点名，也是本项目反复中招的病。

### 先量，再动（本 session 反复的教训）

I3 已经给了 N ∈ {12,16,24,60} 的分布（docs/54），**从它开始，别重测**。
但**宏观池的形状要自己扫**：池按什么缩放（人口？岗位数？在班人次？），
在 12/16/24/60 四档上分别给出什么供给，**先扫出曲线再挑一条**，不要先写公式再找数支持它。

⚠️ **N=12 必须逐字节不变。** 这是本波最重要的一条不变量：
双尺度是为大镇加的，**小镇的行为不许因此漂移**。
⇒ 若你的实现让 N=12 的 digest 动了，**先停下来问为什么**，而不是重烘金标。
   （若确实必须动，走 R12 全套：三锚重烘 + rebake_history + held-out 13-30 两侧。）

### 验收

1. **N=12 逐字节不变**（digest / event_digest / 逐 tick 前缀链，12/12 seed）——或走完整 R12。
2. **N=60 屋瓦不再全年断供**（**这才是 §0.5 的原话**）。
   > ⚠️ **K1 指出我在这里越权加码**：我原本还写了"且 `#40` 的满足率在 N=60 上过（这是 §0.5 的硬要求）"。
   > **§0.5 没有这句话**，它的原文只针对屋瓦断供。按本文 §〇 自己的规矩（表和计划冲突以表为准），
   > **表的要求已达成**；我那句更严的转述**不作数**。
3. **N=16 / 24 也要报**——I3 证明真正的边缘在 16，别只测两端。
4. 缺货的社会后果**仍然逐个 agent 落地**（记恨到具体的人）——给出前后对照。
5. §2.5 三行包络；`bash tools/ci.sh` 全绿（读输出不是退出码）。
6. **一条反向负对照**：把宏观池的供给强行调到 0，`#40` 必须红。
   （防的是"池一接上，判据就再也不会红了"——那正是本波最容易造出来的空门。）
