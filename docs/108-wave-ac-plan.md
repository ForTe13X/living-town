### 我复核过它，属实，而且比它写的更具体

`Inv.digest`（`Invariants.gd:1280`）**只折 `event_log`**：
`id / type / actor / target / accepted / subject / tick / witnesses / note`。
`chain_step`（`:1310`）折的是 `tick_no`，以及**逐 agent 的**：
`id / pos / needs(定点量化) / talking / option 的六元签名`，加上本 tick 的新事件。

⇒ **两者都不覆盖**：`beliefs` · `attitudes` · `factions` · `affinity`/`familiarity` ·
`pacts` · `standing` · `town_stock` · **`space` / `floor`** · `money` · `memory`。

**具体到能吓人的一句**：两个世界里某人都在 `(10,10)`，一个在**咖啡馆室内**、一个在**小镇平面**，
⇒ **`chain_step` 给出相同的哈希。**

⚠️ **这不是新发现，是一个被反复局部撞见、却从没被当成一类处理的东西**：
Q1 早在五波之前就实测过 `chain_step` **不折 `attitudes`**（并因此推翻了 P1 的一步推断）。
**外部评审做的是把它一般化。**

⇒ **本波之后，"逐字节一致"这句话在本仓库里的含义必须是写明的，而不是读者猜的。**

## 四、共同约束（照抄，不重述理由）

- docs/41 红线四条 + §0.5；**改契约 / 改金标口径是用户的决定**。
- **红数不是判据**（X1/Y1/Z2/AA3 四次实测：`obj_dist_penalty` 0.400→0.401 这个语义为零的扰动
  能消掉两个硬红、能把一个岗位的余量从 2 打到 0、也能压穿"商贩在摊子上"那条读法）
  ⇒ **对着零假设臂用连续余量判。**
- **"金标 N/N 不变" ≠ "该 N 不变"**（Y1：另外 48 个 seed 有 31% 会动）；
  **"某条臂让金标动了" 同样是抽样**（AA1：九条臂动的都只有 seed 8，held-out 探测率 4/18）。
- **可比性 ⟺ 两棵树在 `game/scripts/` 与 `game/data/` 上逐字节相同**（Y1 更正）。
- **一个检查若"打印了却不阻止"，它就不是检查**（协调者在 `gate_fixture_audit` 上撞到过：
  它打印 `HARD_IDS ❌ 对不上` 然后照样把不完整烘成基线）。
  **同族的新样本：一次 `git push` 可以退出码 0、报告"已同步"，而它什么都没推**——
  因为分支根本没动。**"成功了"和"做了事"是两件事。**
- **先确认你量的是哪个对象**（H1/S3/V3/W3 四次量错；Y3 补"按条数排序可能就是错的口径"；
  Z2 补"平均在场人数 ≠ 每个 seed 至少被看见一次"；AA3 补"在班 ≠ 在摊位"）。
- **`tee | tail` 会吃掉退出码**；**别在 CI 跑的时候改它正在读的任何文件**。
- **编号是三位数**（`lint_links` 已修，带 10/100/102 回归守卫）；**107 已被别的 session 占用**。
- **worktree 的 checkout 可能落后很多个 commit**：**先确认基线，是祖先才 ff。**
- 隔离副本里做负对照；越界要声明。
