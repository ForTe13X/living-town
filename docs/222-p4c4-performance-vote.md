# 222 · P4c-4 政绩进入连任选票

> 接 [221](221-p4c3-voter-review-preview.md)：每位居民已经能解释自己如何评价上届出勤与财政，本片把同一份可见算式接进真实选票。

换届日先冻结上一任成绩单，再开始新一届计票。每张票仍以选民对候选人的 `standing` 为底分；只有上一任再次进入三人候选名单时，才把该选民的政绩总分加给上一任。未参选的前任不会把政绩转给盟友、同派系或其他候选人。完全同分仍走原有稳定哈希。

新任期记录保存 `review_event_id_used`：首届为 0；后续若前任参选，必须指向紧邻上一届的 `mayor_review` 事件，否则仍为 0。硬不变量 #37 逐届核对这条来源链，避免一份无来源的政绩分进入选票。观察台沿用 [221](221-p4c3-voter-review-preview.md) 的同一评分器，并把标签改为“连任票”，因此玩家看到的分解与引擎实际使用的值来自同一个函数。

`governance_test` 另造一张底分 0 对 1 的选票：不带成绩单时挑战者胜；满勤且镇库 +20 时现任凭 +10 政绩分反超；零出勤且镇库 -20 时仍由挑战者胜。测试同时核对第二届记录是否只在前任实际参选时绑定成绩单。
