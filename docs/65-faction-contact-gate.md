## 〇、判决

**拆成三句，三句的处置完全不同。**

### 1. 「派系是从观点相似度派生的标签、不需要显式 join」——**是设计，有据，我不动**

`docs/10 §S3①` 逐字写着：「每夜 `_recompute_factions()` 从 `attitudes` 单遍贪心派生 `faction` 标签
（对齐=≥2 话题同号且 |Δ|<FACTION_BAND；**非显式 join，观点漂移则派系重组**）」，
`Sim.gd` 的 `factions` 字段也声明为「每夜全量重建的**只读视图**」。

### 2. 「聚类不要求任何接触」——**是缺陷**，三条理由

- **它不是只读的。** `faction` / `faction_size` 直接进**权威判定**：`_acceptance_margin` 里的
  `_faction_term`（±`FACTION_ACCEPT_K` = 8.0）、整条 `endorse` / `rally_oust` 候选支
  （`_social_candidates` 里的 `faction_size >= FACTION_QUORUM`）、以及同派系日常社交的额外亲和
  `FACTION_INGROUP_AFF`。**一个会改变"谁接受谁的寒暄"的字段，不是"视图"。**
- **它解锁的动作，自己的措辞就假设了认识。** `endorse` 写进记忆的是「和%s统一了对%s的看法」（串谋），
  `rally_oust` 是「**带着自己人**去找%s说理」。**你没法带上从没见过的人。**
  机制的语义早就要求接触，只是代码从来没查过。
- **它就是外审「第一刀」真正的落点。** docs/62 §四要的是「B 镇在消息到达前读不到 A 镇那件事」。
  P1 已证 belief 层白拿；**而 attitude→faction 这条，多镇一开就是直通的**（§一）。

### 3. ⚠ **但它【不】与 `Sim.gd:10` 那句自我描述冲突——派棒 brief 这一点说得太满**

原文逐字是：

> `关系账本(affinity/familiarity + event 溯源) + belief/知识边界(只能经事务/观察获知) + 不可变 event_log`

括号里那句「只能经事务/观察获知」**修饰的是 `belief`**，而 `attitudes` 是后来 S2 才加的另一个子系统
（docs/10 §S2，Friedkin-Johnsen + Deffuant 有界信任），**这句话里一个字都没提它**。

⇒ **不是"实现违反了自我描述"，是"自我描述枚举了两条局部性保证
（账本 event 溯源、belief 只经事务），而 `attitudes → faction → 权威判定` 是它没写到的第三条通道"。**
这是**文档缺口 + 代码缺陷**，不是自相矛盾。
说成"违反了 `Sim.gd:10`"会让人去改那句话，而该改的是代码。

### ⇒ 处置

**判为缺陷，加接触门。但修法的能力边界必须一起写清楚（§三）：**
**接触门把【从没见过面的人】那一半打成【逐字节零影响】（25/25 格），
把【见过面的人】那一半只缩小、【没有】清零——而且它按构造清不了。**

## 一、先量：干预实验扩到 5×5 网格（逐 N 逐 seed，给展布不给均值）

**干预**（照 P1 §四）：`tick 1200`，只把**一个人**的私有 `attitudes` 与天生锚 `attitude0` 全设成 `0.9`。
**零事件、零 belief、`event_log` 一个字都没多。** 被改动者 = id 定序后第 `N/2` 位（与 P1 同口径）。
网格：`N ∈ {12,16,20,24,60} × seed ∈ {1,5,7,13,21}`，10 天，`t0=1200`。**25 格。**

### 1.1 本棒相对 P1 的**方法**改动——这一节是全部结论的前提

P1 的推理是：**「@1440 全世界【行为】逐字节相同 ⇒ 1200-1440 之间不可能有 `discuss` 载过那个人的新立场」**。

**⚠ 这一步不成立，而且我实测把它证伪了。**

`Inv.chain_step` 折进去的是 位置 / 需求 / talking / option 签名 / 本 tick 事件——**不含 `attitudes`**。
⇒ **同一 tick、同样接受结果的一次 `discuss`，会在两臂里传递不同的立场值，
而不改变任何行为、不改变 `chain`。**
P1 的 `_fp_rel` 又把【关系账本 + attitudes + faction】折进**同一个**指纹 ⇒ 它也分不出这两件事。

本棒把 `attitudes` 单独拎成一条指纹（`_fp_att`），于是那一步从**推理**变成**直接观测**。

**实测：那个洞真的会漏。** 修复前**出货配置 21 个触发格里，10 格的第三方 `attitudes` 分叉早于派系分叉**：

| 格子 | 别人 attitudes 首次分叉 | 别人 faction 首次分叉 | 行为首次分叉 |
|---|---|---|---|
| **N=12 s7** | **@1335** | @1440 | **@1892** |
| N=12 s13 | @1410 | @1440 | @1400 |
| N=16 s5 | @1218 | @1440 | @1208 |
| N=24 s13 | @1214 | @1440 | @1204 |

N=12 s7 那行最刺眼：**立场在 @1335 就传到别人身上了，而行为要到 @1892 才分叉**——
整整 557 tick 里「行为逐字节相同」为真而「立场没传出去」为假。
⇒ **P1 §四那条推论在大约一半的格子上是错的。**

**⇒ 所以本棒不靠时序，靠隔离。**

### 1.2 隔离臂：**不需要造第二个镇**

`_nearby_agents` 的判据是 `_same_plane(o,ag) and o.area == ag.area`，而 `_same_plane` 比 `space` + `floor`。
⇒ **把被改动者从 tick 0 起钉在一个自造平面 `q:cell` 上**（镇上没有任何人会有 `space=="q"`），
他就**从头到尾**不可能出现在任何人的 `_nearby_agents` 里、也没有任何人出现在他的
⇒ greet / gossip / discuss / confide / 见证 **一条都不可能发生**。

**对照臂是【同样被隔离但立场没改】的那一局** ⇒ 两臂唯一的差别就是那一个人的私有 `attitudes`。

**隔离自证是量出来的，不是断言**：每格打印 `被改动者与人同区 tick` 与 `familiarity 总和`
——**修复前后各 25 格，全部为 `0` / `0.0`（50/50）**。

⚠ 隔离臂**按构造**会让那个人饿穿（硬 `#01` 红），它是**诊断配置不是出货配置**；
两臂的 `starved` 逐位相同（例 N=12 s1：9776 vs 9776），差异不在那里。

## 二、修了什么

### 2.1 一句话

**`_recompute_factions()` 的归堆判据从「对齐」改成「对齐 **且** 打过交道」。**

```gdscript
if _aligned(_agent_by_id[id], _agent_by_id[m]) and _acquainted(id, m):
```

### 2.2 判据为什么取 `familiarity`

`familiarity` 在全仓库**只有两处**自增，两处都是**真的共处并完成了一次事务**：
`_commit_social` 里被接受的社交、以及 `_resolve_commitments` 里守约赴会。
**它从不衰减**（全仓 `grep familiarity` 无减号）。
⇒ **`familiarity >= 1` 恰好等于"至少完整打过一次交道"**，单调、事件溯源。
`_impt` 早就用 `familiarity <= 1.0` 表示"首次接触更显著"——**同一个习语，不是我新发明的口径。**

`_acquainted` **双向都查**，且**不经 `_rel`**：`_rel` 缺键时会**建**一条零关系写进账本，
而本函数每夜要跑 O(N·medoids) 对——那会把"评估"变成"写全镇的账本"（§六·1 给 `_form_pacts_greedy` 记的正是这笔账）。

### 2.3 ablation 开关

`var faction_fam_th := 1.0`，`<= 0` ⇒ `_acquainted` 直接 `return true` ⇒ **逐字节回到 Q1 之前**。

**实测（`analysis/q1/ablation_s0_v2.txt`，本棒全部改动就位后跑的）**：

```
✅ #25 [硬]S3派系派生一致(对齐且相识)  12/12
✅ 金标一致 12/12 seed（含逐 tick 前缀链 12 条）
=== S0 GATE: PASS ✅ ===
```

⇒ **门关时本棒的四处改动（接触门 / 场景种子 / 累计计数 / `#25` 收紧）合起来是逐字节零扰动。**

### 2.4 一起改的：`faction` 定向场景的种子

`_seed_scenario()` 的 `faction` 分支只种**立场**，不种**认识**。门一开，这条定向场景第 1 天一个派系都没有
——**等于把它自己要测的机制关掉了**。照**同一个函数里 `freerider` 分支已有的做法**
（它同样显式种 `trust` / `complementSeen` 这些前置），把两个阵营**组内**的 `familiarity` 种到门线上。
组间不种：立场相反、`_aligned` 本来就不成立，种了也不改变任何聚类结果。
**门关时整段跳过**——否则 `_rel` 会建出关系条目，ablation 就不再逐字节（这条是实测踩出来的）。

### 2.5 一起改的：`#25` 收紧成合取式 + 一个**累计**计数

`#25` 的名字承诺「派系归属与派生规则一致」，而 Q1 之后派生规则是**两个**合取项。
docs/41 §2 第四个盲区（`#39` 名字里的「在班」两个字在实现里没有对应代码）说的正是这种。

**⚠ 但我第一版收紧是【没有牙】的，负对照当场把它打回来了——这一条比修复本身更值得记。**

第一版只查**终态**：跑完时有没有"与医心未谋面的派系成员"。
负对照（隔离副本，只删 `and _acquainted(id, m)` 一处）：

| fixture | 变异体（门被删） | 未变异的树 |
|---|---|---|
| **N=12 × 20 天（= CI 的 N）** | **✅ 3/3 全绿** ← **没有牙** | ✅ 3/3 |
| N=60 × 20 天 | ❌ 0/3（未谋面同派系=15） | ✅ 3/3 |
| N=12 × 1 天 | ❌ 0/3（未谋面同派系=3） | ✅ 3/3 |

**原因**：12 人的镇跑到第 20 天，**人人都已经认识人人** ⇒ 终态判据没有东西可抓。
**这正是 docs/41 §2 第三个盲区**——判据没问题，出问题的是**喂给它的那个世界**。
而 CI 第 4 步恰好就跑 N=12。

**修法**：加一个只观测的**累计**计数 `Sim.fac_unmet_placements`
（决策路零引用，与 `endorse_events` 同一档），在 `_recompute_factions` 的归堆处
**独立于那个合取式再查一次**（故意不写成 `else`，删门的回归才抓得住）。
判据于是从"终态有没有未谋面同派系"变成"**这一局有没有【发生过】一次未谋面的归堆**"。

**同一个变异体、同一个 fixture 重跑**：

```
N=12 × 20 天，门被删 ⇒ ❌ #25 0/3
   首违 seed 1: 对齐不一致=0  终态未谋面同派系=0  全程未谋面归堆=32
                              ↑ 旧判据看到的      ↑ 新判据看到的
未变异的树，同 fixture ⇒ ✅ 3/3（N=12×20d / N=60×20d / N=12×1d 三个 fixture 均无假红）
```

`#25` 现名 **「S3派系派生一致(对齐且相识)」**，三个计数分开报，红的时候一眼看出破的是哪一项。

## 三、修好了什么、没修好什么（这一节比 §二 重要）

### 3.1 从没见过面的人：**逐字节清零，25/25**

`analysis/q1/post_*.txt` 每一格的隔离臂都打印：

```
隔离自证: 同区 tick=0(ctrl=0)  familiarity总和=0.0(ctrl=0.0)
含被改动者 行为首次分叉@从未   chain同=true
```

**25 格全部 `chain同=true`。** 修复前同样这些格子里有 10 格别人换了派系、5 格世界真的分叉。

⇒ **一个从没跟任何人打过交道的人，把自己的私有立场翻个面，现在整个世界逐字节不动。**
**这正是多镇 / 多 domain 那一格**——B 镇居民与 A 镇居民 `familiarity` 恒 0。

### 3.2 见过面的人：**只缩小，没清零**

出货臂（无隔离）修复后**仍然触发 22/25 格**。N=12 s1 的具体形态：
`tie: lin/2 → /1`——**`lin` 与 `tie` 是认识的**，`lin` 立场一变就不再与 `tie` 对齐、改投别的 medoid，
`tie` 于是掉回单人、跌破 `FACTION_QUORUM`，**而 `tie` 没有经历任何事件**。

⚠ **出货臂的"修复前 vs 修复后"不是受控对照**：门从第 1 天起就改变了整条轨迹，
tick 1200 时两边已经是两个不同的世界。所以我**不**报"reach 从 4 降到 1"这类差值当作效应量
——逐格看它**有升有降**（N=20 s13 是 5→8，N=20 s1 是 0→3）。
**唯一受控的对照是隔离臂**（§三·1），那一侧是绝对结果：byte-identical，不需要对照基线。

**为什么按构造清不了**：`_aligned` 比的是对方**当前真实的** `attitudes`。
**任何**建立在真实 `attitudes` 上的全局划分都有这个性质——改一处，划分就重排。
**真正的局部化只有一条路**：让每个 agent 按**自己观测到的**他人立场聚类
（一个 per-agent 的"我以为他怎么想"模型，只在接触时更新）。

**⇒ 我没有做那一条，而且是刻意没做**：那是新增一整层状态 = 架构改动，
而 **docs/41 §0.8 明写架构改动动手前必过外部对抗评审 + 多棒**。建议留在 §七。

**⇒ 本棒诚实的措辞**：不是"派系层的知识局部性修好了"，是
**"【跨接触边界】那一半被打成了逐字节零影响；【接触边界内】那一半仍然存在。"**

## 六、两个同族案子的判决（docs/64 §〇 点名、P1 未展开）

### 6.1 `_form_pacts_greedy()`——**不是同一个缺陷，但有一笔独立的账**

**结果侧已经有接触门，而且比我加的这条严**：`PACT_FAM_TH = 6.0` 查 `_rel(ag, oid)["familiarity"]`，
外加 `complementSeen >= PACT_COMPLEMENT_TH`。两条都只能靠真实互动累积
⇒ **从没见过面的两个人今天就结不成盟约。**
实测佐证：隔离臂里被改动者 `familiarity` 恒 0，25 格里 `pact_formed` 从来没有他。
⇒ **"零接触结盟"这件事不存在，P1 说的"结果大致合理"是对的。**

**但过程侧有一笔独立的账**：那道 trust 守卫是
`float(_rel(ag, oid)["trust"]) < PACT_TRUST_TH or float(_rel(o, id)["trust"]) < PACT_TRUST_TH`，
**而 `_rel` 缺键时会【建】一条零关系**，且这行排在 `PACT_FAM_TH` 那道门**之前**
⇒ 每夜对几乎每一个有序对都会在**双方**账本里各建一条零条目。
⇒ **"A 的账本里有 B 这一条"并不等于"A 见过 B"。**
今天这些零条目是惰性的（`familiarity`/`standing` 全 0，过不了任何阈值），
但**任何以后按"关系条目存在"判断认识与否的代码都会被它骗**。

**我没有改它**：改 `_rel` 的建键语义会动到全仓库最热的一个函数，属于另一根棒。
（本棒的 `_acquainted` 刻意绕开 `_rel`，正是为了不再往这堆里加。）

### 6.2 `_resolve_rally_oust()`——**是【另一类】缺陷，我没有修**

它对 `factions[fac]` 的**每一个成员**（不管在哪）调 `_judge_actor(m, o["id"], false, ag["id"])`
⇒ 缺席者会因为一场自己没看见的合围而改变对 `o` 的 standing。

**判决：这不是"读别人的私有状态"，是"为一件自己没见证的事写自己的账本"——另一类。**
接触门只把它**收窄**（backer 现在至少与医心相识；且它本来就要求 `standing<0` 或与 `o` 有冲突，
两者都只能靠与 `o` 的真实接触积累），**但没有要求 backer 在场**。

**没修的理由（明写，不是遗漏）**：把 backer 限制成"在场者"会把 `rally_oust`
从"派系协同"改成"围观者协同"——那是**改机制语义**，不是修局部性；
而 `rally_oust` 的分档（`FACTION_MOB_DEFER` / `_mob_erupts`）是盲评标定过的
（`Sim.gd` 的 CHARACTER 注释记着 `p_eff=0.014`、CI[0,0.028]）。**动它要重新标定，超出本棒。**
⇒ **建议单独派一棒**，判据形状照本棒 §一·2 的隔离臂（把 backer 钉到另一平面，看 standing 还动不动）。
