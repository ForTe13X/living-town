# 190 · 生活模式：开局选人、附身过日子（Sims 式操控）

分支 `feat/life-mode`（基于 master `41def7d`）。方向转向玩法：从"看小镇"变成"在小镇里过一个人的日子"。

## 一、玩家看到什么

1. **开局选人**：桌面上不带参数启动（或 `--life`）先出选人台——12 位具名居民的立绘、职业、性格；
   选中看简介/日薪/家/钱包，Enter 或双击开始。克隆出来的 `npc_*` 没有自己的人设卡，不上台。
2. **附身**：被选中的人**原样**成为你——家、工作、钱、关系、需求衰减全部照旧（和 M1 的"新居民 player"不同，M1 的需求是冻结的）。
   引擎不再替 TA 挑事；你不下单，TA 就站着，饿了也不会自己去吃。
3. **镜头**：不再是观察者探针。贴身跟随（默认 2×，滚轮 1.1–3.2×），进门/上楼镜头随人换平面，拖拽被禁用。
   头顶一颗"生命水晶"，颜色是最缺的那条需求（绿/黄/红）。
4. **时钟**：tick 从 0.08 s 放慢到 0.5 s（一天 ≈ 2 分钟 @1×），档位 停/1×/2×/4×；
   睡觉这类 ≥30 tick 的动作进入"使用中"就自动 8× 快进，醒了回原档。
5. **操控**：WASD 走（走动会放下手头的事）→ 身边（曼哈顿 ≤2）有东西就浮出 `E 使用 · 灶台` →
   按 E 开菜单（世界暂停）→ 数字键/点击选。点击远处的物件也能直接开菜单，选了会自己走过去。
   - 物件：每个广告位一行（`吃饭 饱腹+55 · 1 小时 48 分 · 3 币`），不可用的灰掉并写原因（店员专用 / 不是你的活 / 现在不开 / 只在自己家里）。
   - 居民：**「怎么开口」**——几种说法（语气·情绪·台词·动词），下面是「直接做」的原动词列表与不可用原因。
   - 门/楼梯：贴身即可进。
   - 自己（点自己或身边没东西时按 E）：放下手头的事 / **自主**（让 TA 自己过一会儿，按方向键收回）/ 换一个人生。
   - **点地走路**（第二批）：点地面走过去（落脚点一圈金环），点远处的门走过去再进；远处物件/居民选了动作会**先按 WASD 同步频走过去**再下单/开口
     （`Sim.life_step_toward` 逐格 A*，不再等 0.5 s 的 tick 慢慢挪）。按方向键随时接管。
7. **每日愿望**（第二批，Sims 的 wants）：左上角每个游戏日按 (人, 天) 确定性抽 3 条——吃一顿/睡个好觉（按当下最缺的需求）、上一次工、
   跟 3 个人打招呼、送礼、约人、和某个还不熟的人说上话、攒到 N 币、趣味涨到 80。完成判定只读 `social_event` / 新信号 `life_action_done` / 状态快照；
   奖励是 View 侧的「满足感」分，日终在纪事里记一行当天完成几条。
6. 右下角人物卡：立绘、职业·在班·钱·地点、正在做什么（带进度条）、五条需求、速度与自主按钮。
   观察台、时间轴、聊天框在生活模式里让位（时间轴回放不含玩家指令，拖它会"改写"你的人生）。

## 二、「说法」：模型只负责怎么说，不负责能不能做

`Sim.life_verb_options(target)` 圈定此刻**开得了口**的动词（与 `_player_act_untraced` 的前置校验逐条同源：礼物、传闻、已约、冲突状态、距离、对方忙不忙）。
`AIBackend.approach_floor()` 是规则地板：按说话人的性格/心情与双方关系挑语气，确定、零 RNG，菜单一打开就有。
`AIBackend.suggest_approaches()` 在 `llm`/`slm` 档把人设、心情、对方性格与心情、相关记忆喂给模型，要 `动作|语气|情绪|台词` 四段式；
`parse_approaches()` 只收合法集里的动词，其余行丢弃；回包到了替换地板（模型没覆盖到的合法动词用地板补），菜单标 `[模型]`。
选中后台词经 `life_social(verb, target, say)` 进入 `last_say` 与气泡，**事务裁决仍按动词走**（对方照样可以拒绝你）；
模型档下再用 `AIBackend.chat` 让对方回一句。

**语气会影响结果**（第二批）：`Sim._tone_term()` 把语气先按关键字归到 10 类（模型给的自由文本也能归），
再按对方性格与交情折成接受判定里的一个加项（约 −8..+9；greet 的判定式量级是 need×0.4+affinity，所以一句话能翻"差一点"的那些，翻不了坏关系）：
热情对热情/豁达的人 +8、对内向/敏感/寡言 −6；调侃只对熟人（familiarity≥8 且无恶感）+8，否则 −8；对方正难受时关切 +9；……
接受了还会按语气给对方多记/少记一点好感（±2..3）。
菜单里只有对**熟人**才标 `〔投其所好〕/〔怕不对味〕`——陌生人你猜不到。
零扰动：加项经 `_tone_bonus`，只在带 `tone` 的单子（只有 `life_social` 会产）上非零；S0 金标 12/12 未动。
confront / apologize 走自己的状态机，不吃语气项。

## 三、引擎侧（Sim.gd）

新增一组 `life_*` 公开动词，全部复用引擎自己的执行路径，没有第二套规则：

| 调用 | 走的是 |
|---|---|
| `possess(id)` / `controlled_id` | `_advance_agent` 里与 `is_player` 同一道"option 为空不决策"门；危机抢占、LOD 远端化对被附身者豁免 |
| `life_move(dir)` | 同平面导航网判可走 → `_move_agent`；清掉当前 option |
| `life_use(obj, action)` | `_apply_object`（收费、工资、库存、cargo 签发都在里面）；cargo 单借候选里引擎签发的那一份 |
| `life_social(verb, target, say)` | `_player_act_untraced(…, actor_id, say_override)`——M1 的同一个函数，参数化了发起人 |
| `life_portal(pos)` | `_try_traverse_portal`（权限照验）；贴身时先迈到门格，被拒退回原格 |
| `life_interactions()` / `life_status()` / `life_verb_options()` | 只读 |

**零扰动**：`controlled_id == ""` 时每个钩子都短路。S0 金标 12/12 seed 一致（含逐 tick 前缀链），det 3/3。
玩家指令不进 `player_trace`（生活模式是游玩路径，不是可回放证据）；`start_new` 清附身，View 在 `world_reset` 后重新附身（存读档、改 NPC 数都走这条）。

WorldView 唯一改动：插值步长的上限在慢 tick 下放开（默认 0.08 s tick 下与原式逐值相同），被附身者按 WASD 步频（0.13 s/格）插值。
