# 221 · P4c-3 选民政绩预评

> 接 [220](220-p4c2-term-review.md)：上一任已有固定成绩单，但“这份成绩在不同选民眼里意味着什么”仍不可见。

本片加入一个只读评分解释器。完整观察台在第一次换届后显示所选居民对上一任的政绩预评，包括出勤、财政和合计三项，并明确标成“未计票”。真实选票仍只读取居民对候选人的既有 `standing`，因此这一片不会改变当选人、任期、日程或世界轨迹。

评分以 50% 出勤为零点，满勤达到正向上限，零出勤达到负向上限。任内镇库变化在 ±20 币内线性换算，超过后封顶。基础权重为出勤 6、财政 4；带有“勤快/严谨/细致”的居民把出勤权重提高 2，带有“务实/多疑/寡言”的居民把财政权重提高 2。所有换算均为整数，且不消耗随机数。

`Sim.latest_mayor_review()` 返回成绩单深拷贝，界面无法借引用改写任期账本；`Sim.mayor_review_score()` 只读取选民、成绩单和数据配置。`governance_test` 用同一份 25% 出勤、镇库 +10 的成绩单证明：勤快选民得到 `出勤 -4 / 财政 +2 / 合计 -2`，务实选民得到 `出勤 -3 / 财政 +3 / 合计 0`；重复调用结果相同，且调用前后的真实选票、任期、事件账本逐项相同。

## 验收

- `governance_test`：评分算例、重复调用、深拷贝、缺配置关闭和真实选票不变全部通过。
- `--obs-fit --agents 12 --warmup 56`：14 位实际居民、名片/卷宗两档共 28 格，溢出 0；最坏内容 653px / 可用 664px，余量 11px。第一版多放了一个空行，实测有 3 格溢出 8px；已删掉该空行后复测转绿。
- DetGate seeds 1-4 × 四场景 × 20 天：硬不变量、同 seed 两跑、数据指纹与现有金标均为 16/16，无需重烘。
- ModelPathGate seeds 1-4 × 8 天：失败 0，四个 random(full) 摘要逐字节对上现有锚。
- `player_touch_test`：0 失败；既有名片/卷宗前缀与版式契约不变。
- `lint_data.py`、`lint_links.py` 与 `git diff --check`：通过。
