### ⚠️ 红线与"可以用 img-gen"这句话怎么并存

用户说过 UI/UX 美术打磨可以走 Chrome 里的 img-gen。**这与红线 #4 / R2 并不冲突，但边界很窄**：

- **而且它绕不过门**：H2 的 `asset_gate` 判的是"出货 == 切图配方当场重建"，
  一张没有配方的生成图**进不了上门表**，只会被记成 WARN 的"手绘无配方"。
⇒ **出货必须是 CC0 切片或自绘像素。** 若你用了 img-gen 做参考，**在回执里写明用在哪一步**。
