## 〇、这一波的起点是一句判决

Wave C 把画面从"调试视图"修成了"能看清的小镇"，并把**量具本身**修好了（`--shot` 此前永远渲不出夜）。
三路独立评审（外部对抗 AI + 两个只读 agent，指令均为 REFUTE）给出的判决是同一句：

> **"它看起来明显更好了，而且仍然没有人会玩它。"**

**Wave C 量的全是【可读性】，而可读性不是【吸引力】。** 本项目至今**没有任何能测 playability 的仪器**，
所以 Wave D 的第一条纪律是：

> **★ R9 · 不许再用画面指标替代玩法证据。** 一个视觉数字（接缝跃变、占屏比、亮度比值）只能证明"看得清"。
> 凡是声称"更好玩 / 更想玩 / 更有吸引力"的结论，**必须指出它靠什么证据**；如果没有证据，就写"未测"。
> 这条是 docs/41 §5「数字要有零假设」的下一级：**先问这个数字回答的是不是你正在声称的那个问题。**

> **★ R10 · 每一波必须有一次"有人把整帧看一遍"。** Wave C 的每一条视觉验收都是点采样或 diff-bbox，
> 于是**三样东西进了每一张已发布素材**（录屏光标、印着原始数据键的缺贴图占位块、一块写着「测试阁楼」的招牌）。
> 计划给音频写了"必须有人真的戴耳机听一遍"，**却没给画面写对应那一句**。现在写上：
> **收尾前必须有一次全帧眼验，且必须覆盖"已发布素材"本身，不只是渲染出来的中间帧。**

### D2 · 给小镇一个单局形状（缺口 #1，**本波最大的一条**）

**独占：新建 `game/scripts/Goals.gd`、`game/data/goals.json`，以及 `game/scripts/Main.gd`。不得改 `Sim.gd`。**

`docs/01 §3.2` 承诺过社会成就（撮合一对、化解一场争执、办一次全员到场的活动），**代码里一个字都没有**。

**架构红线（比玩法更重要）**：它**必须是对 `Sim.event_log` 的只读派生**，与 `ProbeController` 同一纪律。
**绝不能写世界状态**，否则同一存档在不同观看路径下会回放出不同历史——那是本项目最老的一条红线。

**验收**
- headless 场景，12 seed × 14 天：①每个 seed 至少达成 1 条；②**回放安全**——`Sim.goto_tick(t)` 之后
  从 `event_log` 重算的目标状态必须等于 `t` 时刻的实时状态（**这条断言就是"它留在 View 侧"的机器证明**）；
  ③`tools/ci.sh` 金标**逐字节不动**——若动了，说明你写进了 Sim，回滚查因。
- **R9**：不要声称"这让游戏更好玩"。你能证明的是"存在一条玩家可感知的进度线"，**就只写这个**。
- **R10**：收尾前把 HUD 那一条产出图**整帧看一遍**。

### D3 · 点灯的夜 + 玩家有个样子（缺口 #3 #4 #6）

**独占 `game/scripts/WorldView.gd`。不得动 `Main.gd`（D2 在用）、`project.godot`、`Sim.gd`。**

1. **夜里点灯**。现在夜晚是**纯全局乘暗**，实测暖光像素 0、亮度>190 的像素 0。
   窗户暖光（已有夜间窗色的钩子）、门楣灯、广场灯笼、室内透出的光池。
   **注意 C3 已实测的机制**：`CanvasModulate` 乘的是 CanvasItem，**清屏色不受影响**；
   所以"光源"必须画成 CanvasItem 的加色/亮色块，且要在 modulate 之后仍然读得出来。
2. **压住夜里的池塘**。蓝通道在 `_daylight` 里只掉到 0.797，而草地掉到 0.42
   ⇒ **夜里全图彩度最高的东西是两个青色矩形**。让水在夜里跟着暗下去（或给它一层夜色罩）。
3. **玩家不是圆盘**。`Sim.gd:752` 给玩家 `sprite: ""`，于是 `WorldView` 回退到 `draw_circle(#ffd700)`。
   **不要改 `Sim.gd`**——在 View 层给"空 sprite"一个体面的回退（复用既有 CC0 精灵 + 确定性色相变体 + 金环保留）。
4. **派系环换色**。`_faction_color()` 现在是 `Color.from_hsv(hash%360/360, 0.65, 0.95)` 的任意霓虹。
   从 [docs/44](44-art-direction.md) 的 40 色表里取**有限几个**强调色，并让它不再盖住 C1 的柔和椭圆影。

**验收**
- 夜帧：暖光像素数 **0 → >0**（报具体数字与位置）；亮度>190 的像素 **0 → >0**；
  **正午帧 diff bbox 必须是 `None`**（只动夜里的东西）——这是这一棒的天然负对照。
- 水：报夜间水/草地的**彩度比值**改前改后。
- 玩家：`--player` 帧眼验 + 报圆盘像素归零。
- 金标逐字节不动 + `probe_digest_test.sh` 与改动前的树同值（**自己跑基线**）。
- **R10**：整帧看一遍，包括你自己产出的每一张证据图。
