## 二、量出来的

### 1 · 泊位（只加泊位与大勇、渔夫未动；seeds 1-3 × 60 天）

| | P2a（一个码头工） | + 第二泊位 |

| 60 天末还在港的单 | 7-17 | 0-3 |
| 柴薪进口 / seed N=12 / N=16 | 36-56 / 12-24 | 68-80 |
| 口粮缺货 N=12 / N=16（三 seed 合计） | 50 / 379 | 78 / 129 |
| 柴薪缺货 N=12 / N=16 | 163 / 213 | 218 / 254 |

- 船位不再是瓶颈：积压清空、柴薪进口翻倍，N=16 口粮缺货 379 → 129。
- **柴薪缺货反而多了**——不是 bug，是需求跟着涨：泥瓦匠上工多了（seed 1：22 → 31 场，每窑烧 3 柴）、大勇也要洗澡；木匠略少。屋瓦产出 seed 1-2 涨了（660 → 840、440 → 510）。
- 仅泊位时的 #40 网格：N=12 seeds 1-30 失败 12、13、19（27/30），N=16 失败 5（11/12），硬全绿。

### 2 · 海鲜的批量（seeds 1-3 × 60 天）

- 第一版 11 件/场、cap 30、每天坏 2：满足率 **0.15-0.32**——渔夫每 seed 只上 3-7 场，赶集需求 95-176 且随人口涨。
- 改 cap 40、每天坏 1，扫批量：

| 件/场 | N=12 各 seed | N=16 各 seed |
|---|---|---|
| 20 | 0.80 / 0.66 / 0.60 | 0.77 / 0.51 / 0.60 |
| **26** | **0.80 / 0.67 / 0.75** | **0.77 / 0.57 / 0.75** |
| 32 | 0.80 / 0.69 / 0.65 | 0.77 / 0.67 / 0.61 |

  满足率在 ~0.8 饱和：卡在渔夫的场次上，不在批量上。

  渔夫转岗给 #40 加了一种新进判决的特产，而它的供给卡在一个人的场次上（每 seed 3-9 场），批量救不了渔夫不出海的 seed。

  P2a 落地 92、记录 92、**漏记 0**；P2b 落地 99、记录 97、**漏记 2**——t105 阿涛和大勇同时决定去吃饭，都没有记录。
